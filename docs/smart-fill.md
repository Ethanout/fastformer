# F 平面填充

- 空会话中手持方块，瞄准方块面，按 F 识别。活动起形会话内，F 保留切换填充模式的行为。Ctrl+F 保留选区翻转。
- 以实际命中点向面外偏移 0.1 格后所在的方块格为种子，分别在 XY、XZ、YZ 平面进行二维四邻接 BFS。必须找到完整边界；开放、未知或超限的候选平面不可填。若多个平面可填，优先选与命中面平行的平面，其余按法线 X、Y、Z 顺序选取，每次只填一个平面。不沿射线寻找其他起点。
- 若三个平面都不可填或种子不是空气，不写入世界，提示玩家用完整方块围住缺口，并瞄准缺口内的放置位置重试；射线未命中方块时提示如何瞄准。空会话按 F 不切换填充模式，模式切换仅在对应活动会话内可用。超过玩家放置上限或放置材料不可用时仍提示失败。
- 每次只填该平面的一层空气格，支持墙面、地板和天花板。厚墙不自动补深度，不搜索洞穴体积。瞄准坑底时只填坑底上方一层，不自动封坑口。整次填充使用一个世界撤回记录。
- 准星穿过空框命中后面的方块时，以后面的命中面为准，不自动填较近的空框。要填框内平面，需有能命中且外侧一格落在框内的方块作为锚点；已有相邻墙面不影响二维边界判断。
- 仅当填充区域与玩家相交时，首次 F 显示实际方块模型预览。再次按 F 或 Enter 确认，Q 取消。长按 F 不会确认预览。
- 只填空气，不覆盖流体或植物。不完整方块、未加载区块、世界边界和搜索上限均不能充当封闭边界。无法确认边界时不填充。
- 预览固定识别区域、放置朝向和材料。确认前区域或识别边界变化时拒绝提交，需要重新识别。换维度或断线后丢弃待确认预览。

识别最多读取 65,536 格，平面最多 1,024 格，平面搜索距种子格的曼哈顿距离最多 32 格，并受玩家放置上限限制。搜索、预览会话和渲染分别由 `SmartFillSearch`、`SmartFillManager` / `ClientSmartFillSession`、`SmartFillPreviewRenderer` 负责。世界写入复用放置任务、恢复日志和撤回历史。
