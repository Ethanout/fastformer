# 快速起形提交快照身份

Enter 原来只发送确认指令，服务端收到后读取当前草稿。按键与处理之间发生更新时，旧指令可能提交新草稿。

客户端现在在 Enter 回调捕获完整权威快照及其 revision、玩家、维度和连接身份。键盘队列保留此快照。新的确认协议携带身份，服务端拒绝过期确认并返回现有回执。旧协议保留给其他入口。

分片快照未齐时，显示仍保留上次完整版本，但该显示不能提供提交数据。快照复制可变 BlockPos，防止捕获后坐标变化。Enter 的点选择规则集中到 QuickShapeSubmissionPoints，服务端与客户端共用。

## 验证

- 最终完整 `test check runGameTestServer` 通过，89 项必需 GameTest 全部通过，日志为 `.dsh-tmp/quickshape-snapshot-integrated.log`。
- 新 GameTest 验证过期确认不写世界、不结束新草稿，而当前 revision 可以提交。
- 单元测试覆盖网络编解码、过期和跨环境拒绝、分片更新、可变坐标、重连以及键盘队列中的快照保留。

## 剩余边界

此修改建立提交身份，不代表完整提交意图完成。分片未齐仍拒绝当前 Enter，尚未等待数据。客户端生成、计算期间的修改门禁、Q 取消未发送意图、一次性自动发送和生成结果校验仍需接入。服务端暂时仍生成最终形状。实机未验收。
