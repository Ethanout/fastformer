# 2026-09-19 交互提示组件

标签、边框、单部件 Gizmo 和公共 Gizmo 现在携带类型化 `TOOLTIP` 组件。
`InteractionTooltip` 只读取命中结果与已解析的能力，不执行会话操作，也不持有任意回调。
选区面的世界内提示通过边框组件读取。

命中类型中的旧提示接口转发到同一策略，准星与标签提示保留现有入口。
可编辑面保留推/拉提示，不可编辑面保留选择提示，Gizmo 使用命中手柄的文字。
无对应策略或目标类型不匹配时返回空提示。
