# 2026-09-19 边框交互对象迁移

选区场景现在为每个有边界的部件发布 `part_frame` 对象。
其身份包含会话、对象类型和部件实例编号，与标签身份分开。
移动保留身份，空边界不创建对象。

`WORLD_BOUNDS` 组件持有世界坐标边界。场景的 `bounds()` 直接读取该组件，不再另存一份边界。
现有边框渲染通过该访问器读取组件。部件命中改为调用 `PartFrameInteraction.hit`。
普通点击仍要求命中边缘，Ctrl 允许命中整个面。失败目标排除和锁定能力仍由原规则决定。
这次迁移不改变面编辑命中，也不改变相机变换和视觉膨胀。

新增三项测试，覆盖边缘与面命中、距离限制、对象身份和空边框。
选区场景测试补充移动后的边框身份及共享几何检查。
`./gradlew test check` 实际执行并通过，耗时 38 秒。
统一 hover、动作绑定、拖动捕获、边框样式组件及实机验收仍未完成。
