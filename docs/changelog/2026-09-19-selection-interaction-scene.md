# 选区交互场景快照

## 实现

- `ClientSelectionSession` 持有完整、只读的标签与边界快照。
- 部件编辑完成后，控制器发布场景并同步源遮罩。移动、撤销和取消编辑不等待下一 tick。
- 客户端 tick 也发布场景，以覆盖恢复和旧入口。读取场景不会触发计算或修改会话。
- 未变化的部件复用对象。仅改变选择集或提交锁时，保留同一场景。

## 读取与清理

- 标签显示、标签命中、边框、面命中和 Gizmo 中心读取共享边界。
- 环境清理立即发布空场景，并更换会话身份。旧快照保持不变。
- 已删除渲染解析器中的旧边界入口，以及标签显示与命中的重复构造。

## 边界规则

- 世界选区保留完整范围，包括空气。未变换的非长方体也使用选区范围，不再分别计算显示和命中边界。
- 剪贴板部件保留原显示规则：基部件边界不包含堆叠副本。命中采用相同边界。
- 无可用边界时不创建标签。场景不会伪造可命中的对象。
- 失败方块过滤和提交锁判断仍保留。组件不保存另一份选择集。
- 本次不调整已有生成预算、网络载荷或磁盘格式。

## 验证

- 新增 8 项 `SelectionInteractionSceneTest` 测试。
- 覆盖只读发布、快照复用、移动、旧快照保留、编号复用、清理、无边界和控制器即时发布。
- 远坐标标签测试使用实际发布的场景对象，检查显示锚点与命中一致。
- 现有边界测试改为覆盖共享计算。Gizmo 测试在 tick 发布后检查目标。
- `./gradlew test check` 通过，测试实际执行。修改文件的 `git diff --check` 通过。
