# 标签交互组件迁移

## 已实现

- 新增 `ComponentType<T>` 和只读 `InteractionObject`。组件键检查值类型，构造时复制组件表。
- 对象身份包含选区会话身份、对象种类和部件编号。普通编辑保持身份，清理活动会话时更换身份。
- 部件标签使用锚点、命中范围、文字绑定和高亮样式组件。选中、锁定和 hover 状态由调用方读取会话后传入，不在组件内保存第二份状态。
- 标签命中和显示使用同一个世界坐标定义。只有渲染边界减去相机坐标，命中不应用相机偏移。

## 行为变化

保留原有文字规则、命中半径、颜色和缩放反馈。移除 hover 时的轻微上下漂移，使显示锚点与命中中心一致。

## 自动化证据

- `InteractionObjectTest` 四项：组件键隔离、快照隔离、类型检查和对象身份。
- `PartLabelInteractionTest` 七项：共享锚点、高亮、文字与锁定规则、命中范围、非法射线、身份失效和参数检查。
- `WorkspaceInteractionResolverTest` 新增一项集成测试，通过显示组件的锚点命中远坐标部件。
- `./gradlew test check` 成功，测试和模组 jar 校验实际执行。未执行本轮 GameTest 或客户端实机。
