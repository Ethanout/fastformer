# 2026-09-19 选区对象 hover 状态

选区会话的 hover 现在保存一个对象身份、几何快照和命中结果。
标签、边框、单部件 Gizmo 和公共 Gizmo 共用进入、离开及清理逻辑。
边框命中与标签命中通过 `PartSurface` 区分，输入动作不变。

选区渲染器读取会话的 hover 命中，不再为边框与 Gizmo 使用另一份当前命中。
悬浮在部件的面或手柄上时，关联标签仍按原行为高亮。
公共 Gizmo hover 不高亮单个部件。

对象删除、会话清理、提交锁定或几何快照替换会清除旧命中。
几何替换后由下一次帧采样重新命中，不继续使用旧法线与手柄。
同一对象的新命中更新详情，不重复发出进入和离开数据。

新增三项测试，覆盖对象切换、公共对象消失、重复命中及锁定。
已有移动测试改为验证几何替换后的清理，命中测试增加标签与边框来源断言。
全量 `./gradlew test check` 实际执行通过，耗时 38 秒。

进入与离开数据尚未接入类型化业务动作队列。
跨会话的统一 hover、提示组件、动作绑定、物理事件队列及实机验收仍未完成。
