# 选区规则与职责拆分

## 用户确认的规则

- Alt 新建期间保留旧选择集，仅把输入焦点交给新草稿。
- 草稿完成后只选中新选区，保留旧选区和部件。普通点击单选，Ctrl 点击追加或取消选择。
- 普通 CUBOID 空草稿的中键不设点，等待左键设置第一点。Alt 中键保留原设点规则。
- 混合提交成功后清除全部选区和部件，包括未变换且未写入的旧选区。

## 代码边界

- `SelectionBlockCapture` 负责选区方块快照采集及范围变化后的快照复用。
- `SelectionTransformCalculator` 负责移动、缩放、重复和旋转计算。先生成完整结果，控制器再应用结果。
- `client.gizmo` 归类 Gizmo 尺寸、显示策略和绘制。`GizmoRenderer` 接收透明度，不读取预览核心的静态状态。
- `PreviewQuads` 负责基础四边形顶点写入，由 Gizmo 与原预览入口共用。
- 客户端草稿与服务端补点入口均拒绝普通 CUBOID 在第一点之前用中键设点。
