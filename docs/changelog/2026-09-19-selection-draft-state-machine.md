# 选区草稿快照与阶段处理

`SelectionDraftStateMachine` 持有一份不可变草稿。模式、输入点、范围和 prism 底面计数不再分别写入选区会话字段。cuboid 的空、首点和范围阶段，以及 prism 的底面和高度阶段，分别决定事件结果。

`inspect` 只计算下一份快照。`onEvent` 在计算完成后替换当前快照。拒绝事件保留原快照。连续事件可以依次推进，不设置每 tick 一次切换的限制。旧快照不随后续修改变化。

控制器撤销一次恢复完整草稿，不再先恢复点、后恢复范围。撤销保留当前 Alt 状态，环境草稿恢复仍清除 Alt。清空草稿不删除部件，也不重置上次模式。删除三个无调用的旧写入入口。
