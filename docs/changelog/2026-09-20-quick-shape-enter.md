# 快速起形 Enter 数据来源

用户确认：Enter 默认丢弃预备点，只提交已确认部分。专门按键规则优先，目前唯一例外是滚轮模式保留预备点。

- 快速起形伪代码集中定义 Enter 提交规则，各阶段引用同一规则。会话总则明确伪代码是交互逻辑的权威依据。
- TODO 删除所有模式统一固定候选的要求。计算中的等待和重试仍待确认。
- FastPlaceSession 生成独立提交点快照。普通模式只读取已确认点；线阶段 FREE_SCROLL 加入首点与滚轮偏移确定的候选点。零偏移不重复添加首点。
- FastPlaceManager 的生成计划、数量估算和放置效果使用同一份提交点数据。提交快照不修改草稿，后续滚轮变化不修改该快照。
- 删除旧的滚轮候选拒绝条件和对应提示文本。

验证：六项提交点测试覆盖模式差异、快照隔离、模式切入、阶段切换、零偏移及空会话。完整 `test check` 通过，日志见 `.dsh-tmp/enter-submission-rule.log`。两项新增服务端测试通过真实 FastPlaceManager.fill 路径验证世界方块。完整 GameTest 共 87 项通过，日志见 `.dsh-tmp/enter-submission-gametest-retry.log`。首次 GameTest 的新测试未等待其他测试释放写入锁，调整测试准入等待后通过。

本项未完成鼠标输入队列迁移、客户端实机验收或完整提交意图生命周期。提交快照目前在服务端处理请求时生成，不代表客户端按键时快照已经完成。
