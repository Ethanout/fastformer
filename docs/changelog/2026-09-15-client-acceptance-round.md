# 2026-09-15 客户端验收记录

本轮在 `.233` 检查快速起形、草方块提交、选区移动、输入反馈和会话生命周期。

## 已通过

以下按用户“其他的都成功，全部勾选”确认，范围为本轮提供的操作清单。新增失败项不包含在通过结论内。

- 普通起形首点的方块渲染框和外线框显示正常；退化面与零高度体仍失败。
- 普通选区 size/stack 按整体 min/max 尺寸堆叠；旋转后的局部轴仍待复验。
- 移动预览期间，源方块隐藏；取消后源方块恢复，目标虚影清除。
- 工作区显示 Gizmo 和悬浮文字，普通调整可以执行。
- free scroll 连续滚轮时文字持续显示。
- 放置方块的普通 raycast 位于表面；按住 Alt 后改为嵌入。
- 同一方块停留加速和切换目标恢复基准的透明度反馈符合预期。
- 普通 Q 取消、失败后继续操作、退出世界再进入、断线重连和普通小结构放置未发现问题。选区 Alt 故障后按 Q 的恢复仍失败。

## 仍失败

- 确定面阶段准星靠近初始线时，初始线和对应渲染消失。
- 确定体阶段高度为 0 时预览错误；外线框错误地跟随方块吸附点。
- 独立颜色部件之间发生跨部件剔面。
- 方块较多时预览仍闪动。
- 空手选区射线忽略矮草等方块，与原版空手命中不一致。
- 草失去支撑时提交失败。预期为 `CLIENT_ONLY` 下完整成功，不增加草类型特判。
- 旋转后方块不再对齐方块网格。
- 选区会话按住 Alt 后预览全部消失。按 Q 退出后，普通起形首方块预览仍不恢复。

“快速切换多个候选位置”的验收描述不清晰，本轮不据此判断通过或失败。该要求已改写为连续移动候选时不得被旧结果覆盖。
