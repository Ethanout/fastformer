# 瞬时输入状态归属

`ClientInputSession` 由 `ClientPlayerSession` 持有。输入路由、提交门禁、指针令牌、拖动、修饰键、短按和双击记录不再存放在输入类的静态字段中。未绑定玩家时保留一个独立的启动状态，不与玩家状态混用。

作用域切换清理离开的输入状态，也清理重新进入作用域的旧输入。同一作用域的重复观察不重置输入。断线和草稿暂存使用同一输入清理入口，恢复草稿不恢复手势或提交等待。

选区新增瞬时状态清理：取消尚未结束的编辑，释放拖动和 hover，清除 Alt，并更换交互对象的会话身份。它保留草稿和部件。删除全部实时选区数据仍由原清理入口负责。

新增六项测试，覆盖完整重置、旧请求拒绝、作用域隔离、重复观察、跨玩家与服务器切换，以及草稿恢复不恢复提交等待。磁盘草稿加载在输入或提交仍活动时等待，避免清理当前操作。原迟到释放测试改为读取会话持有的指针状态。

只有服务端选区状态、没有本地草稿和手势时，仍允许读取待恢复草稿。服务端返回的选区可以作为恢复确认的依据，不能被当成本地编辑而持续阻塞加载。

本次没有移动物理回调的执行时机，没有完成统一事件队列。输入类仍包含业务分派，选区外的拖动尚未改成类型化组件动作。顶层会话生命周期和客户端实机验收仍需继续。
