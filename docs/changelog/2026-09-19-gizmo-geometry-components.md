# 2026-09-19 Gizmo 几何组件迁移

选区场景为有边界的部件发布 `part_gizmo` 对象，身份与标签和边框分开。
`GIZMO_FRAMES` 保存世界坐标框架与局部缩放框架。
移动和旋转使用世界轴，缩放使用部件局部轴。相机距离仅决定显示与命中的共同缩放参数。
渲染和命中都通过 `SelectionGizmoInteraction.resolvePart` 生成手柄，不分别生成坐标框架。

公共 Gizmo 的范围合并与手柄生成也迁入同一组件系统。
包含棱柱时仍只显示移动和旋转，其余公共 Gizmo 保留缩放。
删除渲染器与命中器中重复的范围合并、棱柱判断和手柄集合代码。
没有改变部件锁定能力、命中优先级、提示文本或拖动规则。

原旋转轴与未旋转轴测试改为验证组件生成路径。
场景测试增加对象身份与空几何断言。新增两项测试覆盖含空气的公共范围及棱柱手柄规则。
新增测试后，全量 `./gradlew test check` 实际执行通过，耗时 34 秒。

公共 Gizmo 尚未具有独立的持久交互对象，句柄动作绑定及统一 hover 仍待迁移。
本次没有完成物理事件队列或渲染资源快照，也没有执行客户端实机验收。
