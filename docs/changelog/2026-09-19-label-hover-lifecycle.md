# 标签视觉悬浮生命周期

- 选区会话持有标签悬浮身份，不以可复用的部件编号作为身份。
- 帧开始时更新视觉状态，标签渲染读取结果，不修改选区数据。
- 对象切换产生先离开、后进入的类型化事件。重复目标不产生事件。
- 删除对象、环境清理、提交锁、屏幕打开和窗口失焦清除悬浮。
- 移动保留对象身份，因此保留悬浮。删除后复用数字编号不会继承旧悬浮。

## 验证范围

- 新增四项 `InteractionHoverTest` 测试，覆盖事件顺序、身份复用、移动、锁定和清理。
- 全量 `./gradlew test check` 通过，测试实际执行。
- 未执行客户端实机验收，尚未证明帧级视觉效果。
