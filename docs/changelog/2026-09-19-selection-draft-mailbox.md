# 本地选区草稿入队

普通 `CreateSelection` 命中和 Alt 新建草稿现进入选区物理事件队列。Alt 直接命中 Gizmo 保留用户确认的例外，仍进入拖动路径。本次不迁移服务端初始设点、快速起形或特殊形状。

## 数据与顺序

`SelectionDraftPress` 固定会话 owner、模式、按钮、坐标、Alt、Ctrl 和发生时间。坐标复制为不可变值，不随鼠标移动改变。分派前检查输入归属、会话、模式、提交、工作区锁和活动拖动。

设点命令按队列顺序作用于当前草稿阶段。它不使用每次编辑都会变化的精确 revision 检查，因此同一 tick 的后续点击不会因前一次合法设点被拒绝。恢复加载继续受物理队列门禁约束，取消和环境切换继续使旧队列失效。

新建草稿、部件选择和拖动共用 `SelectionPointerCapture`。新按下先取消旧拖动捕获。释放只结算其对应编号，不产生第二次设点。旧同步新建分支已删除，未迁移手势取消后重新尝试进入队列。

## 行为边界

Alt 无命中仍消耗修饰键短按并进入 Alt 模式，不新增草稿历史。普通中键空草稿，以及 Alt 新建是否清除选择集，已请求用户确认。在得到答案前保留现有规则。此处“清除选择集”不删除旧部件。
