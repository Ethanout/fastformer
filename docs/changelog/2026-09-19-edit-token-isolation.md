# 编辑令牌隔离

- 原编辑令牌仅包含局部序号。不同会话的首次编辑会得到相等的令牌。
- 改用私有构造的实例令牌，只有创建令牌的活动编辑接受它。
- 清空、恢复草稿和开始新编辑后，旧令牌不能完成或取消当前编辑。
- 控制器拒绝旧令牌时不发布场景，也不刷新源遮罩。
- 面拖动和 Gizmo 拖动检测到编辑失效时停止。手势失效但编辑仍有效时取消编辑，释放编辑锁。

## 验证

- 新增三项测试，覆盖跨工作区令牌、恢复后的旧令牌，以及控制器拒绝后的无副作用。
- 全量 `./gradlew test check` 通过，测试实际执行。
- 网络与磁盘格式不变。此令牌只存在于客户端内存。

## 剩余范围

- 对象、按钮和手势身份的统一捕获仍未完成。
- 客户端实机、断线和换维度的拖动验收仍需执行。
