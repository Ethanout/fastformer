# 2026-09-13 选区移动冲突审计

## BUG-06

`SelectionOperationTask` 的移动路径先在 `CLEAR` 阶段清除源方块，再在 `PLACE` 阶段按 `KEEP_EXISTING` 判断目标是否可替换。目标不可替换时原逻辑直接跳过写入，不标记失败；当平移方向使目标位于选区外且对应源位置已被清空时，源方块会丢失。

修复将该跳过分支与源所有权关联：如果对应源位置已被本任务清空，则先确认该位置仍是任务期望的空气状态，再恢复源快照；外部修改或恢复失败会使任务失败。`SelectionJournalPrediction` 同步恢复该位置，保证恢复 journal 的预测终态与实际终态一致。

本次未修改 Enter/滚轮、预览、源遮罩或交互规范。客户端实机、断线/换维度和真实进程中断仍不由此测试替代。
