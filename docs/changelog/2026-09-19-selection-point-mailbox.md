# 已有选区左右键设点入队

普通左右键落入 `WORKSPACE_ADJUST_OR_CAPTURE` 时，通过选区物理事件队列执行点编辑。直接命中交互对象和 Alt 新建仍优先处理，原有左右键网络通道及原版让行判断保留。

`SelectionPointPress` 固定会话 owner、部件编号、实例身份、按钮、世界落点和发生时间。没有落点时仍捕获原本归选区所有的按钮，释放后清理捕获，不建立编辑。

分派重新检查选区归属、活动部件及实例身份。删除后复用编号不能接受旧事件。连续点编辑允许更新同一实例，不用变化中的范围 revision 拒绝第二次点击。控制器接受明确的部件编号，并在每次编辑前执行现有真实世界源检查；没有客户端世界时拒绝，不绕过检查。
