# 面光栅化：生产入口接入

日期：2026-11-14。范围：手册第 10 节的第一阶段。

## 已接入

- `QuadFaceGenerator` 和 `PolygonFaceGenerator` 使用 `FaceRasterDispatcher`。默认分别使用 `CURRENT_QUAD`、`CURRENT_POLYGON`；分类实验策略命名为 `CLASSIFIED`，不改变生产默认形状。
- 两种入口仍分别调用原有填充、轮廓和失败兜底；不改坐标、边界、遍历顺序或 `TranslatedScan`。生成器原有的空结果兜底继续保留。
- `PrismGenerator` 的底面轮廓和 `TiltedBoxGenerator` 的轮廓经对应入口接入。棱锥的实心截面原本调用多边面生成器，因此随该入口接入。
- 算法注册表构建后冻结；默认调度器可复用。新增参数重载允许调用者为单次面生成传入不可变 `FaceRasterPolicy`，没有全局策略 setter。任务、预览和服务端策略同步尚未接入。
- `LimitExceeded` 在生成器的 Set 边界还原为原有类型化上限标记；最终方块才通知生成观察者，不将上限标记当作真实方块发布。取消异常继续传播。
- `BresenhamColumnVolume` 的六个独立面已接入 `CURRENT_VOLUME_FACE` 和 `ChainExhaustion.RETURN_FAILURE`。任一面不适用、无候选或超限时立即停止，不退成线框；整块体积成功前不发布已暂存的面。

## 对比测试

新增 `ProductionFaceRasterTest`：生产生成器与原有算法入口逐坐标、逐顺序比较，覆盖全部六种分类、两种入口、所有填充模式、QUAD 的所有 tie bias、负小数坐标、重复/共线点，以及上限。另覆盖棱柱与斜盒体轮廓、单次策略不污染默认策略、观察者与取消。

使用实验报告中已存在的差异样本，断言两种原入口仍保持不同结果，防止误用统一默认策略。已有 `FaceRasterAdaptersTest`、几何测试和 GameTest 保留。

新增 `StrictVolumeFaceRasterTest`，覆盖原始法平面结果、六面调用顺序、实心／空心体积坐标和顺序、后续面失败、工作量上限与取消。2026-11-14 接续会话完整 `check --no-build-cache` 通过，2644 项单测、0 失败、0 错误、1 跳过；全新目录的 320 项必需 GameTest 通过。验证证据见主进度中的接续会话记录。

## 仍未完成

1. 严格失败边界已接入体积生成；后续策略传递须保持此契约，不得恢复通用边缘兜底。
2. 生成器的不可变策略参数尚未向上传入复合体积、任务参数和预览快照；数据包加载、同步、哈希校验也未接入。当前调用仍使用各入口原策略。
3. 专用快速算法只保留注册，不改变生产默认链；尚不能宣称通过等价门槛。
4. 两种入口的默认形状统一、四边形策略切换和删除 `TranslatedScan` 均按用户决定暂缓。旧 `PlanarFaceRasterizer` 分派保留在入口适配器内部，待严格失败边界和完整策略迁移后再拆除。

本阶段不涉及网络注册、客户端手势、主进度索引或架构检查工具；没有提交。
