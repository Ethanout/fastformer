# 几何手设计原则

这些是默认判断，不是死规则。用户意图、游戏内证据和形状数学优先；失效的默认规则应删除并补回归测试。

## 三条原则

### 打断原则

如果当前实现开始往“屎山”方向靠近，应暂停开发，给出尽量简短的具体建议。先确认这是用户有意为之还是疏忽，再继续行动。

### 不要重复原则

如果类似代码在多个地方完成相同功能，且代码不短或信息量较大，应复用。先找已有组件；只有真正减少复杂度时才抽取。

### 组件原则和组件互斥原则

优先组合而不是继承。组件只承担一个职责，互相不覆盖功能。

- 起点、射线靠近、拦截视线、单击交互、常态颜色、hover/active、Gizmo 几何、Gizmo 文本和文本块显隐分别组织。
- 一个对象可以挂载多个互不重叠的组件；组件只提供数据和局部行为，不知道具体形状 workflow。
- 组件接口应能独立测试；如果必须读另一个组件的内部字段，边界就不清楚。
- 不引入完整 ECS。数据记录、枚举和小型不可变策略对象足够时，不再增加框架层。

## 拆分与组合判断

适合拆成组件的内容同时满足至少两项：

- 有独立状态或校验规则；
- 被两个以上形状或阶段复用；
- 可以单独测试或替换；
- 改变它不应修改形状生成数学。

不应拆分：只有一条局部判断、没有独立语义、拆出后需要来回传递大量上下文的代码。

工作流保留形状语义：阶段、模式、候选点、参数和生成器由 workflow 组合。共享层只放真正同义的动作、控制点、命中目标、数值约束、预览计划和小型数学工具。

## 核心概念

- `GeometryWorkflow`：一个形状的阶段、输入、预览和生成入口。
- `GeometryStage` / `GeometryAction`：阶段能力和语义动作，不使用 first/second 这类序号命名。
- `GeometryActionContext` / `GeometryHit`：玩家视线、修饰键、raycast 和精确命中信息。
- `ControlPoint` / `ControlPointRole`：控制点的角色、形状和几何位置。
- `ControlPointState` / `ControlPointFeedback`：确认/候选/派生状态，以及可选的 hover 视觉反馈。
- `PointerInteraction` / `GeometryInteractionTarget`：命中区域与手势到动作的组合。
- `GeometryRayVisibility`：把世界首个遮挡面转换为统一的可见远距上限。
- `AxisGizmo` / `TransformFrame`：移动、缩放、旋转以及世界/局部坐标。
- `HoverFeedback`：normal、hover、active 三态；active 默认沿用 hover 颜色。
- `GizmoTextContext` / `GizmoTextTemplate` / `GizmoTextComponent`：受控变量、模板和文本显隐。
- `GeometryPreviewPlan` / `GeometryTextBlock`：workflow 输出的预览、交互目标和可定位文本块。
- `ScalarAdjuster`：滚轮到受限数值的映射。
- `GeometryBuildResult`：扫描估算、生成结果和阻塞原因。
- 形状生成器：具名参数到方块的形状私有算法。

调用点应接近：

```text
具名状态 + 输入协议 + 阶段动作 + 约束/变换 + 预览计划 + 形状生成器
```

## 默认不变量

- 近距离交还原版；服务端持有权威状态，客户端辅助缺失时降级。
- 输入数值先检查有限性，再归一化、clamp，并在写入处再次限制；对外显示清理 `-0`。
- 预览、估算和生成使用同一份派生参数。
- 起点青色，关键控制点黄色，可闭合 hover 绿色；RGB 只表示 Gizmo 的 XYZ。
- 方块中心和特殊 POINT 的视觉标记使用完整方块大小并带同色轮廓；视觉包围盒不反向扩大交互命中盒。
- 已确认结构使用白色面和轮廓；未确认结构使用细的流动虚线。预览超限时保留边界和操作方向。
- 准星附近只放 Gizmo 实时轴和值，以及必要的 Alt 视觉反馈；滚轮/偏移数值放在中下方并短暂渐隐；其他位置只放不重复预览信息的提示。
- Alt 准星优先使用 NeoForge 可取消的 GUI 层和独立 PostChain；嵌入模式使用留有中心空隙的 X，表面半格点使用细圆环和中心针点；后处理不可用时保留可见回退，不影响操作。
- 动态数值立即显示，最后一次输入后约 1.5 秒渐隐。

形状的 `SOLID`、`HOLLOW`、`OUTLINE` 和性能上限以 `docs/generator_baselines.md` 为准；不要建立万能体素化器。
