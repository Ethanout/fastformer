# 选区删除、撤销与快速替换

## 提交与重叠

Enter 和 Ctrl+Enter 都提交全部选区，包括未选中的选区。末尾未完成的选区按当前预览补齐后一起提交。
没有有效预览时保留草稿，不猜测范围。提交不再经过单独固定或全选步骤。

同一坐标按选区建立顺序合成，后建立的非空气方块覆盖先建立的方块。
复用选区编号、点击选中和移动不改变这个顺序。空气不遮盖下层内容。
预览和服务器共用合成规则，每个坐标只写入一个最终状态。目标放置优先于源位置清除。

服务器先采样完整结果范围，再准备完整恢复日志，最后写入世界。
写入回调引起的范围内连锁变化纳入同一条世界历史，每个位置保留一次原始快照。
提交期间，目标区块和相邻区块的计划刻延后执行，随机刻暂缓，结束或取消后恢复。
玩家直接修改仍可发生，并由提交冲突检查处理。这不使用全局 tick freeze。

## 删除选区

- Delete 或 Backspace 删除已选中选区对应的世界方块。未选中的选区保留。

- 选区尚未完成时，删除范围使用已有点和按键时的预备点，与预览共用体积计算。

- 尚未形成有效体积的棱柱不会猜测删除范围。

- 移动预览尚未提交时，删除会清除对应的源方块。不会先把预览放到目标位置。

- 剪贴板预览只从工作区移除，不删除它下面的世界方块。

- 多个选区共享源方块时，未选中的选区优先保留这些方块。

- 删除直接提交，不再经过红色的待删除预览。提交失败时保留选区。

- 删除后没有剩余选区或待设置点时，退出选区会话。

- Ctrl+Delete 或 Ctrl+Backspace 沿用移除预览的操作，不修改世界。


## 撤销与重做

Ctrl+Z 先撤销本地选区操作。本地历史用完后，继续撤销世界修改。
Enter 提交或 Delete 删除后，Ctrl+Z 只撤销世界方块修改，不恢复已提交的选区会话。
没有修改世界的空内容提交也不会留下重新打开会话的撤销记录。

没有活动选区或待设置点时，Ctrl+Y 可以重做世界修改。
部分删除保留未选中的选区及其源方块。剩余选区后续提交时重新采样世界基准。
世界撤销和重做不会替换这些选区。

存在方块冲突时，Enter 强制覆盖，Ctrl+Enter 只撤销无冲突部分，Q 取消。

世界历史仍使用原来的持久化存储。部分删除等待期间会保存剩余选区，供断线后恢复。

## 快速替换

R 开关快速替换会话，左上角显示当前模式。
手持方块并按住右键，替换准星命中的表面方块。
目标使用原版方块外形和当前交互距离，预览与服务端使用同一套计算。
其他操作使用原版行为，快速替换会话不使用近处与远处的输入交接。

替换保留新旧方块共有的状态属性，例如楼梯朝向。
每次成功替换记为一条世界历史，可以使用 Ctrl+Z 和 Ctrl+Y。
一次长按目前不合并为一条历史。

## 多选控件

多选时只显示并拾取整体变换控件，隐藏各选区的独立控件。
整体控件略微放大，并显示选区数量。
