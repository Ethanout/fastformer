# 会话设计

本文只描述概念和状态树，是交互语义的唯一完整来源。实现细节、生成不变量和兼容边界分别写在其他文档。

## 概念

输入
    玩家按键、滚轮和远距离 raycast。

动作
    工作流理解的意图，例如输入点、确认、回退、切换模式、调整数值和拖动 Gizmo。

会话
    一次连续操作。起形、几何、操作三种会话互斥。

阶段
    会话的主节奏，定义当前允许的动作和推进条件。阶段用语义命名，不用 first、second。

模式
    同一阶段下的不同输入协议，例如半径、直径、三点定面。

子模式
    当前模式的临时变化，通常由长按 Alt 启用，松开后退出，不跨阶段残留。

候选
    当前视线推导出的、尚未确认的点或结构。候选不等于状态，Enter 不消费候选。

控制点
    带角色、形状和位置的几何输入；确认/候选/派生状态与 hover 反馈由独立组件提供。起点、关键点和可闭合点可以组合不同组件。
    方块中心与特殊 POINT 使用以精确坐标为中心的完整 1×1×1 视觉框；确认点同时显示同色实体和线框，视觉尺寸不改变交互命中范围。

交互目标
    由 AABB 和手势动作组成的远距离命中对象，例如已确认控制点或闭合起点；命中距离不穿过世界首个遮挡面。

Gizmo
    对当前对象或已选控制点进行移动、缩放、旋转的交互对象。点级 Gizmo 只提供 MOVE，不显示初始位置。

参数
    半径、高度、偏移、缩放、旋转和填充模式等具名状态。

工作流
    一个形状的阶段、模式、输入、预览和生成入口。

任务
    分 tick 修改世界的过程，不属于会话；任务结束后会话才回到空。

## 状态机（行为树）

会话
    空
        远距离右键可放置物品
            创建起形会话并确认首点
        远距离右键不可放置物品
            创建操作会话并确认选区首点
        Ctrl+Alt
            打开几何轮盘
        特殊物品远距离右键
            执行一次性动作

    起形
        点
            远距离右键确认首点
            空会话显示 raycast 候选点的流动虚线框
            默认嵌入命中方块内部；若 Alt 已有其他子模式语义，则由该子模式处理

        线
            AXIS
                选择世界轴方向
                Alt 子模式选择坐标平面
            FREE_SCROLL
                视线决定方向
                滚轮决定距离
            RAYCAST
                默认嵌入命中方块内部
                若长按 Alt 已声明其他子模式，则由该子模式解释命中点
            右键确认第二点

        面
            COORDINATE_PLANE
                由基础线和坐标平面确定第三点
            PARALLELOGRAM
                基础线成为完整边
                滚轮调整沿线错位
            POLYGON
                右键持续输入点
                右键起点或双击右键闭合
                Enter 可提前生成多边形底面
                若继续建体，闭合底面后进入高度
            右键确认普通面

        体
            QUAD
                沿底面法线或自由方向确定高度
                法线高度取有限远距视线与法线轴的最近点；候选和高度导引线共用同一结果
            POLYGON_PRISM
                沿底面法线确定高度
            POLYGON_PYRAMID
                确定顶点高度
            右键或 Enter 确认

        左键
            松开时短按回退一步
            没有可回退步骤时退出起形会话
        长按左键
            不回退
        Q / Esc
            取消并退出
        Enter
            使用已确认状态提前生成

    几何
        墙体
            路径
                右键添加点
                raycast 默认浮于命中表面；长按 Alt 时嵌入命中方块
                起点青色，关键点黄色
                只有真正靠近起点时显示绿色闭合反馈
                右键绿色起点或双击右键闭合
            挤出
                滚轮调整高度
            右键或 Enter
                生成

        球体
            起形
                RADIUS
                    中心 + 半径点
                DIAMETER
                    两个直径端点
                Alt 短按切换模式
                Alt 长按进入精确子模式：命中面外侧方块中心或整数坐标边角点
            调整
                Gizmo 移动和单轴缩放
                按需求保留或关闭旋转手柄
            左键
                从调整返回第二点阶段
            右键或 Enter
                生成

        任意凸多面体
            点集
                右键添加至少四个不共面的点
                Alt 长按使用半格精度
                已确认点左键或右键只负责选中
                选中点显示点级 MOVE Gizmo
                Gizmo 左键或右键拖动只移动选中点
                选中后命中其他位置只清除选中；下一次点击恢复正常交互
                最多 64 个输入点
            Enter
                生成凸包

        锥柱台体
            底面
                RADIUS
                    中心 + 半径点
                DIAMETER
                    两个直径端点
                THREE_POINT
                    三点定圆和底面
                Alt 短按切换模式
                默认嵌入命中方块并使用 1 格精度
                Alt 长按切换到命中表面并使用 0.5 格精度
                Alt 点准星使用细圆环和中心针点，选点预览不显示边或面
                底面确定后显示候选轮廓
            体
                右键只确定沿底面法线的有符号高度
                视线靠近中线时以锥体开始
            调整
                滚轮调整顶面大小或横向偏移
                Gizmo 对整体移动、缩放和旋转
                Alt 短按切换世界 / 局部坐标
            右键或 Enter
                生成

        复杂形状
            轮盘页面
                当前只提供进入、返回和取消
            特殊模式
                曲线、截面、扫掠和放样的交互待设计

        几何会话通用
            近距离命中
                原版逻辑
            远距离命中 Gizmo
                进入拖动
            远距离命中交互目标
                执行目标绑定动作并消费本次点击
            命中其他位置
                交给当前阶段的普通输入
            滚轮
                仅在阶段声明可调整时消费
            Alt
                短按切模式，长按进入子模式

    操作
        选区
            CUBOID
                两点确定轴对齐范围
                左键保留端点和选区面调整语义，不承担普通撤回
            PRISM
                多点确定底面和高度边
                右键设点/闭合/确定高度；左键只撤回，不设点或拖点
            CONVEX_HULL
                至少四点确定凸包，中键添加附加点
            选区完成即显示操作 Gizmo，不再通过 Enter 进入调整阶段
        TRANSFORM
            同时显示世界 XYZ 移动箭头、旋转环和 scale 外形的 repeat 手柄
            同轴连续 repeat 线性增加；不同轴 repeat 形成笛卡尔积
            子选区 Gizmo：总体移动、各自 repeat、各自中心旋转
            多选公共 Gizmo：总体移动、整体占用 AABB repeat、绕公共中心整体旋转
            普通旋转按 90 度吸附；Alt 使用整数斜率 atan2 像素吸附；Ctrl 自由旋转
        SWEEP / LOFT
            保留独立节点和参数，不清除 TRANSFORM 状态
        Alt 短按
            在 TRANSFORM、SWEEP、LOFT 节点间切换；拖动开始后 Alt 只控制替代吸附
        调整撤回
            第一次非零 Gizmo 变换进入调整状态
            调整状态下空白左键只撤回最近一次调整，不穿透选区编辑历史
            撤回最后一次调整后保留选区并退出调整状态
        Enter
            不确认选区阶段；提交整个客户端工作区
            服务端在任何写入前验证全部世界来源、方块/NBT、限额和目标快照
        多选区与剪贴板
            最多 10 个固定编号槽；空槽按最小编号复用，Ctrl+0 对应槽 10
            每个子选区有独立 Gizmo；多选时额外显示公共 Gizmo 和铂白流动虚线范围框
            Ctrl+C 跨会话持久保存解析预览；Ctrl+V 创建独立子选区且不退出工作区
            Delete/Backspace 暂存删除并显示红色移动斜线；Ctrl+Delete 仅移除已选子选区对象

## 全局回退

右键
    推进当前阶段；当前阶段声明确认时表示确认。

左键
    按各工作流语义处理；操作 Gizmo 命中优先于撤回，操作调整撤回与选区编辑撤回相互隔离。

Enter
    生成当前工作流已允许生成的状态；操作选区不再使用 Enter 确认阶段。

Q / Esc
    取消会话或任务。

任务完成
    返回空会话。
