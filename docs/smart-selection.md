# 智能选区

智能选区替代交互入口中的定向棱柱。长方体和智能选区可以保存在同一个选区栈中。

空会话底部显示当前工具：空手显示选区模式，手持可放置物品时复用起形会话线阶段的文字和样式。线阶段显示横平竖直、自由滚轮、视线落点，并高亮当前模式。选区模式读取上次使用的工具。智能模式下，空会话首次左键不执行操作，也不进入选区会话。

底部提示保留纯悬浮文字。最下行与原版物品名共用位置：切换物品时先显示物品名，物品名消失后显示操作提示。模式文字在上一行，提示换行时继续向上排列。动作栏消息显示期间，底部模组文字暂时隐藏。

原版接管时，左上角填充模式和底部提示与世界预览共用透明度进度，一起淡出。回到 FF 接管后一起淡入。任务进度和提交等待信息仍保持可见。

选区取点默认命中流体，按住 Alt 时穿透流体。流体预览和取点均使用实际流体形状与液面高度，包含水源、岩浆源和流动液体，不使用整格方块框。起形放置和距离接管的射线规则不变。智能选区已有的 Alt 逐格编辑仍使用选区格拾取。

## 操作

短按 Alt 在长方体与智能选区之间切换。按住 Alt 配合鼠标时，执行组合操作。

| 输入 | 智能选区行为 |
| --- | --- |
| 右键 | 从命中方块开始，选择相连的同类型方块，忽略朝向等状态属性 |
| Alt＋右键 | 穿透世界遮挡，添加命中选区格的面外相邻格，空气也可添加 |
| 左键 | 从未固定智能选区移除命中的整个连通区域 |
| Alt＋左键 | 使用同一穿透射线，移除命中的一个选区格，包括空气格 |
| Enter | 优先固定栈末尾正在编辑的智能选区，之后显示变换控件 |
| 滚轮移动 | 固定并移动选中的智能组；下一次右键另建新组 |
| Q | 采样时取消采样，否则沿用选区栈的取消操作 |

存在正在编辑的智能选区时，隐藏全部变换控件。剔除后不自动拆分选区，各部分保留同一个编号和变换归属。

减选和 Alt 逐格增选只影响未固定智能选区，不修改世界方块。Enter 固定后不能继续逐格编辑。

Alt 左右键共用完整方块格拾取。左键移除命中格，右键添加命中面外的相邻格。没有命中未固定智能选区时不执行操作。空气成员保留在选区、撤销记录和存档中。

栈末尾有未确认智能选区时，普通右键新增的区域都加入该组，不要求接触，也不限制组内距离。完全固定的组不参与合并。若新建长方体待设置点或追加其他选区，先自动确认原智能组；未确认智能组只能位于栈末尾。撤销新建操作会恢复该智能组原来的编辑状态。

## Enter 的优先级

1. 末尾有待设置点：结合当前预览补足长方体，进入两点锁定状态，仍可中键扩展或推拉面。
2. 末尾为两点锁定长方体或未确认智能组：将该组完全固定。
3. 末尾无需补足或固定，且有选中组：只提交选中组，保留其他组。
4. 没有选中组：全选现有组。

Ctrl＋Enter 跳过上述分阶段确认，补足当前预览后直接提交全部组。采样和提交等待期间不重复确认。部分提交的剩余组随提交记录保存，支持断线恢复。

## 相似度与数据包

搜索只使用上下、左右、前后六个相邻方向。每个候选方块都与最初点击的方块比较，避免不同材质族连续扩散。

普通右键匹配相同方块 ID。材质族匹配器及 `fastformer:selection_families/` 标签保留，当前没有绑定输入。Alt＋右键只添加单格。

数据包可以新增材质族标签，或用 `replace: true` 覆盖内置标签。这些配置目前不影响左右键操作。例如，文件路径为 `data/fastformer/tags/block/selection_families/custom_stone.json`：

```json
{
  "replace": false,
  "values": ["minecraft:stone", "minecraft:stone_bricks", "minecraft:stone_brick_stairs"]
}
```

本次内置 26 个材质族标签。标签随数据包同步，执行 `/reload` 后生效。

一次搜索最多选择 65,536 个方块。搜索分帧执行。超过上限或遇到未加载区块时，放弃本次搜索并提示原因，已有选区保留。已被移动预览隐藏的源位置不参与搜索。

## 显示

- 保留天蓝色方块轮廓，普通操作按实际成员与方块形状拾取。空气成员用淡轮廓表示，按完整格拾取。智能选区的外包盒不参与选中判定。

- 同一个智能选区内部存在不相连的部分时，显示屏幕四角 L 形框和共同编号。连续的智能选区不显示 L 形框。

- 固定并选中不相连的智能选区后，显示变换控件的位置和距离。控件在屏幕外时，显示方向提示。

- 不相连选区的整体跨度超过 64 格时，在下方提示。跨度按最外侧方块中心构成的包围盒对角线计算。提示适用于选中或正在编辑的选区。

- 按住 Alt 编辑时保留世界画面，智能选区使用天蓝色实心方块格和深色格线。空气成员也显示为完整方块格。固定选区使用灰色。被遮挡部分使用 50% 不透明度连续混合，松开 Alt 恢复普通轮廓。

- 方块格采用原版方向明暗：顶面 100%、南北侧面 80%、东西侧面 60%、底面 50%。遮挡处混合 50% 选区颜色与 50% 世界画面。

- Alt 编辑统一使用白色操作框，标记射线命中的完整方块格。该框使用蓝色选区的深度，只显示未被选区挡住的线段。世界方块不会截断该框，框随选区一起参与遮挡透明混合。左右键共用该框，按键不再改变框的颜色或将框移到相邻格。左键移除命中格，右键添加命中面外的相邻格。

透明叠加只覆盖智能选区的像素，选区轮廓外的遮挡方块保持原样。渲染使用缓存方块格网格、独立选区缓冲、世界深度拷贝和一次合成，不扫描遮挡方块，不重建世界区块网格。

## 撤销与模式记忆

新增、合并、剔除和固定均进入选区历史。撤销与重做恢复当时的成员、编号、固定状态和工具模式。

显式切换工具会更新下次进入选区时使用的模式。历史回放恢复历史工具，但不改写该偏好。当前偏好保留至客户端退出，尚未写入磁盘。

## 实现与验证

搜索、相似度、拓扑分析、成员编辑、采样和屏幕投影分别位于独立类中。分离区域标记与普通左键减选共用拓扑缓存。缓存记录每个方块所属的连通区域，点击直接查询归属，成员变化后重新计算。拓扑不拆分选区归属。旧棱柱枚举保留用于读取历史数据。

测试覆盖连通块移除、单格剔除后分离、撤销与快照恢复、固定状态保护、半砖形状、六个方向的增减选拾取、空气成员存档和遮挡面的模型保留。
