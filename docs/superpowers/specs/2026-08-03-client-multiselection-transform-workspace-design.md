# 客户端多选区变换工作区设计

## 目标

将操作阶段改造成客户端编辑器式工作区。玩家可同时维护最多十个子选区，使用每个子选区的独立 Gizmo 或多选公共 Gizmo 完成平移、旋转和 repeat；Ctrl+C/V 提供持久剪贴板；Delete 暂存世界删除；Enter 将全部调整作为一次可恢复世界操作提交。

操作节点精简为 `TRANSFORM / SWEEP / LOFT`。本规格实现 TRANSFORM；SWEEP 和 LOFT 保留独立节点与状态入口，不在本轮定义世界执行。

## 权威边界

`ClientOperationWorkspace` 是编辑状态的唯一持有者，包含子选区、选中集合、活动编号、临时变换、工作区撤回历史、Gizmo 交互、渲染缓存和剪贴板引用。拖动期间不逐步同步服务端。

服务端只负责无法安全下放的边界：

- 验证玩家、维度、创造模式、功能开关和协议；
- 在提交时重新读取世界来源，检测编辑期间的外部变化；
- 验证方块状态、方块实体数据、目标范围、数量和内存预算；
- 按稳定顺序合成目标，通过恢复日志原子写入；
- 维护提交后的世界 undo/redo 历史。

客户端预览不是最终世界权限。服务端拒绝提交时，客户端保留工作区并标记失效部件。

## 客户端状态模型

```text
ClientOperationWorkspace
├─ parts: slots 1..10
├─ selectedIds
├─ activeId
├─ mode: TRANSFORM / SWEEP / LOFT
├─ adjustmentHistory
└─ previewCache
```

每个 `SelectionPart` 保存：

- 稳定槽位编号；删除后新建内容复用最小空槽，已有编号不重排；
- AABB、棱柱或其他既有选择体定义；
- 世界来源或剪贴板来源以及方块状态/方块实体快照；
- 平移、旋转、repeat、轴心和待删除状态；
- 当前实际占用方块的整数 XYZ AABB；
- 自身 Gizmo 和预览缓存版本。

Ctrl+1..9 选择对应编号，Ctrl+0 选择 10，Ctrl+A 选择全部。一次创建或粘贴必须整体落入剩余槽位，否则完全拒绝。

## 命中与选中

- Ctrl+点击 Gizmo、编号标签或边框：追加/取消多选。
- Ctrl+点击普通世界方块：沿用当前 AABB/棱柱语义创建新的子选区，即使方块位于已有选区内部。
- 普通点击 Gizmo、标签或边框：单选该子选区。
- 拖动已选 Gizmo：保留多选。
- 拖动未选 Gizmo：先单选该子选区。
- Ctrl+拖动未选 Gizmo：追加到多选后拖动新集合。
- Ctrl+Delete 移除全部已选子选区对象，但不修改其世界方块。

## 两层 Gizmo 语义

每个子选区始终显示独立 Gizmo。多选时额外在选中集合的整数占用 AABB 中心显示公共 Gizmo。

| 拖动对象 | MOVE | REPEAT | ROTATE |
|---|---|---|---|
| 子 Gizmo | 全部已选部件整体平移 | 每个部件按自身整数占用 AABB 分别 repeat | 每个部件绕自身中心分别旋转 |
| 公共 Gizmo | 全部已选部件整体平移 | 按选中集合整体整数占用 AABB repeat 整组 | 绕公共中心整体旋转 |

变换节点同时显示移动箭头、repeat 方块手柄和旋转环。不同变换保留各自状态，一次完整拖动只产生一条工作区历史。

## 组合框

多选时使用世界 XYZ 对齐的整体 AABB 框住全部已选部件。组合框使用白金色流动虚线与八个短粗角标，不填充表面。公共 Gizmo 位于中心。

拖动子 Gizmo 时对应子框和 Gizmo 高亮；拖动公共 Gizmo 时组合框高亮，子 Gizmo 降低透明度。整体旋转后重新计算世界对齐整数占用 AABB。

## 整数占用 AABB

AABB、棱柱和其他选择体使用完全相同的 repeat 与粘贴间距算法。不得直接以浮点几何边界计算宽度；先枚举最终实际占用方块，再计算：

```text
min = selected block coordinates component-wise minimum
max = selected block coordinates component-wise maximum
width = max - min + 1
```

多选整体盒是所有参与部件实际占用盒的并集。该规则避免棱柱边界的浮点误差造成意外空一格。

同轴 repeat 线性增加重复次数，不重复放大已有同轴整体；不同轴形成笛卡尔积。公共 repeat 使用组合整体宽度，子 repeat 使用各自宽度。

## 旋转

- 无修饰键：90° 吸附，使用精确整数坐标和可旋转 block state 变换。
- 长按 Alt：吸附到 `atan2(a,b)` 小整数斜率集合，其中 `a,b` 为 0..10 且不同时为零；约分去重后镜像到完整圆周。
- 长按 Ctrl：自由角度，不吸附。
- Alt 被有效拖动消费后，松开不切换操作节点；未产生有效操作的短按 Alt 才循环节点。

非正交旋转使用确定性体素化。预览和提交共享同一纯函数输出；冲突以稳定源坐标顺序解决，不允许客户端和服务端分别解释。可正交旋转的 block state 在 90° 倍数时同步旋转；非正交角度不能可靠表达的状态保持原值。

## Axiom 式方块预览

开始变换后，客户端屏蔽有世界来源的移动源方块正常区块渲染，并用原方块模型绘制半透明留影。目标位置使用原方块模型和材质绘制较实的呼吸预览。复制来源不被屏蔽。

旋转、repeat、粘贴和组合操作都渲染最终体素化方块，而不只画体积线框。取消、撤回或退出工作区后立即恢复被屏蔽的正常方块渲染。

Delete/Backspace 将所有已选世界来源部件标记为待删除，不立即写世界。待删除方块表面显示类似 World Border 的红色移动斜线。剪贴板来源且尚未落地的部件被 Delete 时直接从工作区移除。Enter 统一提交待删除和其他变换。

## 剪贴板

Ctrl+C 复制所有已选部件的当前预览结果：包含已应用但未提交的平移、旋转、repeat、多个部件的相对位置、方块状态和方块实体数据；不复制待删除标记。

剪贴板使用版本化、压缩、原子替换的客户端文件跨世界、服务器和游戏重启保留。读取损坏或版本不兼容时保留原文件并提示。

活动工作区 Ctrl+V：

- 以复制内容整体整数占用 AABB 的最小宽度轴为正向偏移轴，平局按 X、Y、Z；
- 偏移距离为该轴完整宽度，使新部件紧贴但不重叠；
- 新部件成为唯一选中集合，不退出操作状态；
- 连续粘贴每次创建新的独立部件集合。

空工作区 Ctrl+V：

- 射线命中表面作为锚点；
- 剪贴板与命中法线相反的一面中心和落点重合，例如命中 +Y 面时使用剪贴板 -Y 面；
- 创建工作区、进入 TRANSFORM 并生成待放置部件，不立即写世界；
- 无有效落点时拒绝并提示。

## 合成与提交

多个部件目标重叠时，高编号覆盖低编号；同一部件 repeat 单元按固定 XYZ 顺序合成；空气透明；待删除不参与目标合成。预览与服务端提交使用相同顺序，重叠处显示细红边提示。

Enter 将源清除、待删除和目标放置合成为一次世界事务。服务端在任何写入前完成来源摘要、目标快照、数量、内存和权限验证。失败时不进行部分写入；写入中异常使用持久恢复日志回滚。

## 撤回和退出

工作区调整历史与初始选区设点历史分离。空白左键在发生调整后撤回最近一次完整工作区命令；不能穿透到其他子选区的设点历史。退出工作区丢弃所有未提交调整并恢复本地渲染，持久剪贴板保留。

## 测试边界

- 十槽分配、最小空槽复用、Ctrl+0/1..9、Ctrl+A 和容量原子拒绝；
- Ctrl 命中路由、未选/已选 Gizmo 拖动及活动编号；
- 子/公共 Gizmo 的六种 group/local 变换语义；
- 棱柱实际占用整数盒、最小轴粘贴和无浮点空格；
- 90°、Alt 整数斜率、Ctrl 自由旋转及客户端/服务端体素化一致；
- 源屏蔽生命周期、目标呼吸预览、删除斜线和撤回恢复；
- 剪贴板版本、压缩、原子写入、损坏恢复和空会话表面锚定；
- 高编号覆盖、空气透明、repeat 顺序和一次原子提交；
- 外部世界修改、超限、无权限和非法 NBT 均在写入前拒绝。
