# 选区语义化交互设计

## 目标

取消“Enter 确认选区后进入调整阶段”的额外门槛。选区一旦具备有效体积，就直接显示操作 Gizmo；首次有效拖动或 stack 后进入调整状态。不同选区模式保留各自鼠标语义，调整状态中的空白左键只撤回一次调整操作。

## 输入语义

### 棱柱

- 右键继续承担设点、闭合和高度输入。
- 中键语义保持现状。
- 左键不设点、不插点、不选择或拖动控制点。
- 未调整时，空白左键撤回一次选区编辑。
- 命中操作 Gizmo 时，左键用于拖动 Gizmo，不触发撤回。

### AABB

- 左键继续承担第一个端点和现有左键面调整语义。
- 左键不承担普通选区撤回。
- 中键、右键语义保持现状。
- 进入调整状态后，命中 Gizmo 时左键拖动；空白左键撤回一次调整操作。

### Enter

- Enter 不再确认选区或切换阶段。
- 有有效选区但尚无调整时，Enter 不产生零位移世界任务。
- 已有调整时，Enter 直接执行当前可执行操作。
- Ctrl+Enter 保留复制式执行语义。

## 自动进入操作状态

- `selectionReady` 成立时即可显示操作 Gizmo。
- 第一次产生非零 MOVE、STACK 或 ROTATE 变换后，`adjustmentStarted=true`。
- 操作节点首次可用时默认 `MOVE_STACK`；短按 Alt 仍切换操作节点。
- 节点切换不清除各节点的参数。
- 选区再次变得不完整时，清除所有调整状态和调整历史。

## Gizmo 可见性

- MOVE_STACK 节点显示 MOVE 箭头和 SCALE 外形的 repeat 手柄，不显示旋转环；这里的 SCALE 外形仅表示重复次数，不执行几何缩放。
- ROTATE 节点只显示旋转环。
- 准星射线接近选区当前整体 AABB 中心时，Gizmo 总体透明度为 `100%`；其他时候为 `50%`。
- “接近”使用与视距缩放后的 Gizmo 中心命中半径判断，不依赖固定世界距离。
- hover、active 手柄仍沿用现有强调样式；总体透明度只作为乘数，不改变 XYZ 颜色语义。

## 连续 MOVE / REPEAT 模型

### 位移

`translation` 表示整个当前格阵的世界坐标位移。repeat 后再 MOVE，会移动原选区与全部重复副本。

### repeat 格阵

使用三个轴向重复区间：

```text
X: [minX, maxX]
Y: [minY, maxY]
Z: [minZ, maxZ]
```

初始均为 `[0,0]`。最终副本集合是三个区间的笛卡尔积；原点格始终存在。

一次沿正 X 的 `repeat n` 直接增加 n 个重复单元：

```text
maxX = maxX + n
```

负方向对 `minX` 做对称扩张。Y/Z 相同。因此初始对象正 X repeat 3 得到 4 份；再正 X repeat 1 得到 5 份。同轴只线性增减计数，不把当前整体再次倍增；只有不同轴的区间通过笛卡尔积相乘。

### 拖动事务

- 按下 repeat 手柄时冻结格阵基线。
- 拖动过程中使用“基线 + 当前手势总步数”重算预览，不逐包指数叠加。
- 拖回 `0` 恢复按下前状态。
- 松开时只有最终状态不同才写入一条调整历史。
- MOVE 和 ROTATE 使用相同的一次拖动一条历史规则。

## 撤回

- 选区编辑历史和调整历史分离。
- `adjustmentStarted=true` 时，空白左键只撤回最近一次调整，不允许穿透到选区编辑历史。
- 撤回最后一次调整后退出调整状态，保留当前有效选区。
- 棱柱未调整时的左键继续撤回选区编辑。
- AABB 未调整时的左键不撤回。
- Ctrl+Z 的既有全局/会话路由保持不变。

## 世界执行和预览

- MOVE/REPEAT 继续使用现有扫描、冲突校验、方块实体快照、恢复日志和历史提交路径。
- repeat 目标位置由当前区间格阵、原选区尺寸和 `translation` 共同计算。
- MOVE 模式仅有一个格阵单元时移动原结构；存在多个格阵单元时，执行结果包含整个格阵。
- 客户端轮廓预览使用同一格阵枚举，不能与服务端任务分别解释 repeat。
- 最大方块数和内存预检使用格阵单元数乘以实际源方块数，并使用除法式上限检查避免溢出。

## 被否决的方案

1. 同轴按当前整体跨度倍增：会让 `+X 3` 后的 `+X 1` 从 4 份跳到 8 份，不符合 repeat 的计数语义。
2. 保存任意偏移集合：表达能力更强，但当前只允许 XYZ 轴规则，会增加序列化、预览和内存复杂度。
3. 每次 repeat 立即写世界再重新选区：破坏连续预览和一次提交的撤回语义。

## 测试

- 棱柱左键路由不再产生设点/点拖动请求。
- AABB 左键不进入会话撤回路由。
- ready 选区无需确认即可产生 Gizmo 变换。
- 同轴 repeat `+3` 后再 `+1` 得到 5 个 X 单元。
- 不同轴 repeat 形成笛卡尔积，例如 X 4 份与 Y 2 份得到 8 个单元。
- 正负方向、跨 XYZ 和拖回零均可恢复。
- repeat 后 MOVE 会平移全部目标。
- 每次完整拖动只生成一条调整历史。
- 调整撤回不会改变选区点；最后一次撤回后退出调整状态。
- 编解码、预览格阵和服务端目标枚举保持一致。
