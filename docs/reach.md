# 方块交互范围与会话入口

方块交互范围以玩家现有的 `minecraft:player.block_interaction_range` 属性为准。首次初始化时，若基础值仍是原版默认值，则设为 20 格；之后不覆盖玩家修改。重连、换维度和重生保留该值。不修改实体交互范围。

## 命令

```text
/ff reach
/ff reach <整数>
```

不带参数时显示当前有效值和基础值；带参数时设置基础值，保留属性修饰器。有效范围受原版属性约束。没有 `close`、`far`、`reset` 或 `/ff tinker reach` 子命令。

## 输入与预览

空会话没有距离交接状态，也没有手动／自动控制开关。

- 范围内普通交互遵循原版入口；空手且存在可用扳手动作时优先执行扳手。双击右键或 Alt＋右键进入对应会话。
- 超出范围时扳手不生效，右键直接进入起形／选区；显示相应方块虚影或选区预览。
- 会话入口使用真实方块外形，不用加粗射线或完整方块格替代不完整方块。
- 近距离双击以首次原版黑框命中及交互前形状快照为准。FF 普通选点包含流体实际形状；按住 Alt 或玩家已在水中时穿透流体，仍命中含水方块的实体部分。
- 活动会话继续使用自己的输入规则，不按距离重新分配输入。

双击时间、快照恢复、嵌入入口和惯性保护见[空闲会话](principles/pseudocode/sessions/01-空闲.md)。选点、撤点和提交见[选区会话](principles/pseudocode/sessions/10-选区.md)，本文不另维护一份状态机。

## 强制放置

默认开启。创造模式普通放置使用 FF 朝向解析与撤销事务，可放置无支撑等原版不允许的状态；仍检查世界边界、加载范围、交互距离和写入锁。门的上下两格属于同一事务。

```text
/ff forceplace true
/ff forceplace false
```

设置按玩家保存。关闭后使用原版放置流程。
