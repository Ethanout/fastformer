# 近处拾取与输入切换

FF 的方块候选蓝框按真实外形绘制。显示蓝框时隐藏原版黑框；FF 预览退出后恢复黑框。选区体积和空气中的几何控制点仍按其自身范围绘制。

仅在 FF 与原版的进入、退出判定中，可拾取的不完整方块按完整方块格处理。该判定的近处射线半径最多为 0.25 格，逐渐减小至 20 格处归零。判定结果不覆盖原版准星命中，原版黑框和操作使用原版射线。FF 放置、扳手、选区和预览按方块真实外形取点，不使用加粗容差。选区和空手首点预览不跳过草，预览与点击共用拾取规则。扳手在选定方块后使用真实外形判断连接部位，点击西侧连接的南面仍调整西侧连接。

默认小于 3 格切入原版。回到 FF 的距离读取玩家当前的原版属性：方块读取 block interaction range，实体读取 entity interaction range。等于边界时保持当前状态，没有命中时回到 FF。活动选区继续拥有输入。

创造模式首次启用时，方块与实体的有效交互距离默认设为 20 格，包含原版创造模式加成。之后不逐帧覆盖属性；命令或其他模组修改属性后，切换使用修改后的值。

## 命令

```text
/ff reach close 3
/ff reach far 20
/ff reach 3 20
/ff reach reset
```

命令接受 0～64 的整数，far 遵循原版属性范围。双参数与 far 修改要求 close 小于 far。close 只修改进入原版的距离。far 修改玩家的两项原版交互属性。双参数形式同时修改，reset 恢复 3／20。旧的 set、block 和 entity 子命令已移除。

## 强制放置

默认开启。原版接管时，创造模式右键直接使用几何手的朝向解析和撤销事务放置方块，绕过支撑与碰撞等原版放置条件。世界边界、加载范围、交互距离与写入锁仍有效。

```text
/ff forceplace true
/ff forceplace false
```

设置按玩家保存。关闭后使用原版放置流程。

## 选区

空手左／右／中键进入会话，分别设置点 1／点 2／点 1。每个栈项保留明确的点 1 和点 2 槽位。

- 左键：栈顶缺点时重设点 1。栈顶完整时，新建 `[点 1, null]`。
- 右键：栈顶缺点时重设点 2。栈顶完整时，新建 `[null, 点 2]`。
- 中键：栈顶缺点时填入空槽。栈顶完整且未移动时扩展它。空栈或栈顶完全固定时，新建 `[点 1, null]`。
- Q：弹出栈顶。待补点和完整选区使用同一规则。空栈时保留会话。

两点齐全后，选区进入未移动状态，可用中键扩展或推拉面调整大小。多个未移动选区可以共存。新建下一项不会固定旧选区。Enter 固定栈顶完整选区，移动固定所移动的选区。移动后即使回到原位也保持固定。只有一个点时，Enter 不会生成单方块选区。

Q 按创建顺序弹出，和当前选中的选区、显示编号无关。弹出完整选区后，前一项恢复选中，保留原来的几何与固定状态。撤销 Q 可恢复被弹出的项，包括仅设置点 2 的状态。

待补点时，点击用于设置点，已有面、标签和 gizmo 不抢占输入。没有待补点时，已有控件保持点击优先级。Alt 保留穿透选区取点的行为。gizmo 命中容差保持此前的 1.5 倍，显示尺寸保持不变。
