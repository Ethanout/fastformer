# 操作历史磁盘设置

启动一次服务器或进入存档后，编辑 NeoForge 生成的 `fastformer-server.toml`，然后重启服务器或重新打开存档。

```toml
[history]
playerDiskMiB = 1024
totalDiskMiB = 8192
```

`playerDiskMiB` 限制单玩家历史文件总量，`totalDiskMiB` 限制当前存档全部玩家的历史文件总量。单位均为 MiB，范围为 1 到 1048576；两项限制同时生效。批次和索引都计入，替换索引按净增长检查。

降低上限不会直接删除既有文件。下一次需要增长的保存可能失败；世界修改仍保留，后台会重试，并通过聊天通知保存结果。

历史文件位于存档的 `fastformer-history` 目录，按玩家 UUID 分开。当前已接入后台保存，尚未启用重启后撤回和磁盘缓存加载；请勿把这些文件视为已经可用的重启恢复功能。自动保留期限及崩溃遗留文件清理仍待完成。
