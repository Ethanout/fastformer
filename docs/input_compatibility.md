# 输入兼容边界

本文只定义事件所有权和网络降级；按键与阶段语义以 `docs/session_design.md` 为准。

- 只有创造模式、功能开启且目标在远距离时才消费 FastFormer 输入。
- 近距离左键、右键、中键和滚轮交还原版；客户端只有确认消费后才取消事件。
- 客户端负责操作工作区的子选区、选择集、历史、Gizmo 命中、变换预览和持久剪贴板；拖动期间不发送服务端变换 payload。
- 远距离几何右键点输入使用服务端权威 raycast payload；近距离不发送该 payload，继续交还原版。
- 操作选区 ready 后直接显示半透明 Gizmo：准星接近当前整体中心时为 100%，否则为 50%。
- 棱柱远距离左键只撤回选区编辑；AABB 未调整时保留原左键语义。首次有效 Gizmo 变换后，空白左键只撤回一次调整。
- Ctrl+左/右键在世界中创建新子选区；Ctrl+点击 Gizmo/编号/框切换多选，Ctrl+A 全选，Ctrl+1…9 与 Ctrl+0 选中固定槽位。
- Ctrl+C 复制当前解析预览；Ctrl+V 粘贴为独立部件。活动工作区沿整体占用 AABB 最小宽度轴偏移完整宽度；空工作区按命中面锚定。
- Delete/Backspace 暂存世界删除，Ctrl+Delete 移除所有已选子选区对象。操作 Enter 不再确认选区，而是分块提交完整客户端工作区。
- 服务端不接管选择、拖动和工作区历史；只在 Enter 后检查创造权限、维度、限额、源方块指纹、方块/NBT 合法性和全部目标快照，并通过恢复日志执行世界写入。
- 当前 payload 协议版本为 `54`；新增或改变 wire 结构时递增版本。
- optional payload 保证缺少客户端辅助的玩家仍可连接和使用命令降级。
- 其他模组更早取消同一事件时，FastFormer 放弃，不使用 mixin 强抢。

纯服务端通过 `/ff action cycle|adjust|confirm|back|cancel|submode` 提供最小控制。命令不模拟候选 raycast、交互目标命中或 Gizmo 拖动。
