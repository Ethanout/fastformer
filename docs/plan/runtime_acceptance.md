# 运行验收矩阵

这些项目需要开发客户端或真实专用服务器验证。每次测试记录操作 ID、结构方块数、`firstWriteMs`、`afterFirstWriteMs`、总耗时和是否出现错误提示。

## 首块延迟

1. 在空地分别执行 1、16、256、4096 和 32768 方块的小结构。
2. 记录从确认输入到首个可见方块、以及首个方块到完成的时间。
3. 重复每种规模至少 10 次，比较中位数和 P95。
4. 检查首块前没有等待撤回历史压缩；日志中的 `firstWriteMs` 与画面观察一致。

## 状态与取消

1. 在生成、快照、journal、写入、收尾和恢复阶段分别取消一次。
2. 确认每次取消只触发一次动作；部分写入会恢复，未写入时不显示回退进度。
3. 完成后立即执行撤回，确认历史批次可用且方块状态正确。
4. 持续按住 Ctrl，按下 Z 后在恢复期间松开 Z；恢复完成后再次按 Z。对 Y 重复相同步骤。每次新的按下都应执行一次操作，长按自动重复不得新增操作。

## 世界生命周期

1. 任务运行时卸载目标维度、切换维度、断线、重连和关闭客户端。
2. 重新进入后确认任务、预览、journal 和恢复任务状态一致。
3. 重启服务器后确认未完成 journal 被恢复，已提交 journal 不重复写入。

## 冲突与边界

测试虚线框时，在长方体选区边缘保留空气，只在中央放置方块。推拉面后进入工作区，检查可编辑虚线框、面高亮和命中位置均覆盖完整选区。随后移动结构，检查结果框和实际预览一致。

1. 写入前后在目标位置进行外部修改，确认冲突提示可理解且外部修改不会被覆盖。
2. 覆盖普通方块、方块实体、流体和会触发邻居更新的方块。
3. 验证 32768、131072、262144 和超过 262144 方块的放置与撤回。

## 预览与输入

1. 普通起形分别使用 `outline`、`hollow` 和 `solid`，确认方块预览面与外线框同时可见；连续移动准星、转动视角和移动相机时，线框不漂移或消失。
2. 选区移动期间确认源方块隐藏、目标虚影显示且相邻面不重复；成功、取消、冲突失败、超时和断线后分别确认源方块、虚影、Gizmo 和输入状态恢复。
3. 移动、旋转、缩放和堆叠工作区部件，确认 Gizmo 和外框按 `min/max` 整体范围定位；锁定部件保留外框但不产生普通面命中反馈。
4. 空手近距离破坏、持方块近距离操作、首点等待第二点、普通 raycast 与按住 Alt 的嵌入 raycast 分别验证原版让行和预览/提交一致。
5. 执行复制、粘贴、提交成功，以及空剪贴板、无落点、协议不支持、状态变化、存储异常、服务端拒绝和超时，确认 actionbar 原因清楚且成功/失败后的草稿可按预期重试。
6. 在同一方块停留超过 100 ms、切换目标、离开目标、失焦和换维度，确认计时器基础约 1 秒、停留时最高约 3 倍、切换目标立即恢复基础速度。

## 结果证据

每项测试保留：复现步骤、结构规模、操作 ID、服务端 metrics 日志、画面状态、最终世界状态和失败阶段。没有这些证据时，不勾选 `current_todo.md` 中对应条目。
