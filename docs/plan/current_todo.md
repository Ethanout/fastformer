## 交互、存储与模块

- [x] **CODE-07 · 拖动取消与替换**
  客户端取消时发送所属手势的结束包。服务端取消会话时清理活动手势，但保留请求水位。有效的新手势可以替换旧手势。GameTest 验证连续增量、Q 退出后重建、合法完成及旧完成包拒绝。

- [x] **CODE-08 · 选区采样预算**
  扫描前限制包围盒体积为 200 万格。草稿、来源检查和调整共用每 tick 2 毫秒预算，每个任务每 tick 最多读取 4,096 格。只在客户端线程读取世界，遇到未加载区块明确失败。取消、世界切换和所有权失效会停止读取与发布。不可变结果移交不再整表复制。
  自动化覆盖稀疏扫描、格数与时间预算、未加载区块、取消、替换、世界切换和不可变移交。来源检查完成后需再次发起调整，结果只保留 2 秒。扫描性能数据见下表。

- [x] **CODE-12 · 异步保存**
  客户端先取得不可变快照，再由单线程执行器压缩和写盘。工作与未消费结果合计最多 3 个。文件写入票据阻止旧保存覆盖新文件或重建已删除文件。草稿与回执均保存成功后才允许发送。取消或换会话后，迟到结果不发送，未发送回执记录为可重试。退出时最多等待后台写盘 5 秒。
  测试覆盖模拟慢盘、磁盘异常、过期写入、原文件保留、保存先于发送以及取消后的迟到完成。
