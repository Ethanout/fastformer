## 语义事件转换

| 当前状态 | 事件及条件 | 下一状态 | 状态动作或拒绝原因 |
| --- | --- | --- | --- |
| 任意 | Reset | IDLE | 失效手势，清理请求和提交来源，即使原本为 IDLE 也执行 |
| SUBMITTING | Observe | 保持 | 提交未结束，不接受观察覆盖 |
| CANCELLING | Observe(IDLE) | IDLE | 失效手势，清理请求和来源 |
| CANCELLING | Observe(其他合法观察状态) | 保持 | 等待取消完成 |
| 其他 | Observe(与当前相同) | 保持 | 不改写状态 |
| 其他 | Observe(不同合法观察状态) | 观察状态 | 失效手势，清理请求和来源 |
| BUILDING、GEOMETRY、SELECTING、ADJUSTING、SUBMITTING、PLACING | Cancel | CANCELLING | 失效手势，清理路由请求和来源 |
| IDLE、RESTORING、CANCELLING | Cancel | 保持 | INPUT_BLOCKED |
| BUILDING、GEOMETRY、ADJUSTING | Submit，身份合法且无活动请求 | SUBMITTING | 保存请求和提交来源，失效旧手势 |
| 其他 | Submit | 保持 | INPUT_BLOCKED |
| 允许提交的状态 | Submit，已有活动请求 | 保持 | REQUEST_ACTIVE |
| 允许提交且无活动请求 | Submit，身份非法 | 保持 | INVALID_REQUEST |
| SUBMITTING | SubmissionCompleted，身份匹配且成功 | 回执携带的合法观察状态 | 清理请求和来源，失效手势 |
| SUBMITTING | SubmissionCompleted，身份匹配且失败或过期 | 提交来源状态 | 恢复路由归属，清理请求和来源 |
| 非 SUBMITTING 或请求身份不匹配 | SubmissionCompleted | 保持 | STALE_REQUEST |

合法观察状态不包含 SUBMITTING 和 CANCELLING。提交参数及观察参数的构造校验应在切换前完成。以上动作只描述路由，不证明草稿、世界和服务端恢复已经同步完成。

## 当前队列边界

- `ClientInputSession` 分别收取提交完成事件和物理输入事件。键盘、候选滚轮及已迁移的选区鼠标路径共用物理队列，保持发生顺序。
- 输入会话 reset 使 mailbox 中的旧事件失效，并清理手势、修饰键与短按记录。
- 请求身份匹配是回执推进路由的必要条件。队列失效和请求匹配是不同的保护边界。
- 取消仍在回调中即时决定，接受取消后使旧物理队列失效。未迁移的鼠标路径先收取更早的队列事件，再执行原同步路径。这一兼容边界仍待删除。

## 选区鼠标迁移矩阵

| 当前归属 | 按下事件 | 分派动作 | 拒绝与释放 |
| --- | --- | --- | --- |
| 选区 | 普通左／右键命中部件、标签、边框 | 按固定 Ctrl 值选择部件 | 目标或 owner 失效时拒绝，配对释放只清理对应捕获 |
| 选区 | 普通左／右键命中 Gizmo | 为固定目标开启编辑 | 释放结算对应拖动，迟到释放不能结束新编辑 |
| 选区 | 普通左／右键命中面 | 按当前能力选择或开始面拖动 | 源检查继续读取真实世界，释放结算已接受的编辑 |
| 选区 | Alt + 左／右键直接命中 Gizmo | 变换旧部件或公共选择集，消耗 Alt 短按 | 按下固定 Alt，松开 Alt 不改变拖动归属 |
| 选区 | 普通 CreateSelection 命中 | 用固定坐标和按钮推进当前草稿阶段 | owner、模式、提交或锁状态不允许时拒绝，释放只清理捕获 |
| 选区 | Alt 新建草稿，且不命中上述 Gizmo 例外 | 用固定世界落点推进草稿，保留现有 Alt 规则 | 无命中只消耗修饰键短按，不新增草稿历史 |
| 选区 | 普通左／右键调整活动选区点 | 使用固定落点编辑固定实例，重新检查真实世界源 | 活动部件、实例或 owner 改变时拒绝；无落点不编辑，释放仍清理捕获 |
| 选区 | 普通中键，已有本地选区 | 用固定落点扩大当前实例范围 | 2026-09-19 用户确认：归属选区即拦截原版，无变化、无落点或校验失败也不让行；释放清理捕获 |
| 选区 | 新按下替换队列捕获 | 先取消旧编辑，再检查新目标快照 | 回退使新快照失效时拒绝，不能继续使用取消前的几何 |
| 已不归属选区 | 迟到的选区按下 | 拒绝业务动作 | 已拦截的输入不补发原版动作，释放清理对应捕获 |

以上路径已迁入物理队列。服务端初始设点、旧手势兼容分支、其他会话鼠标和业务 hover 仍待迁移。表格记录实现边界，验证结果见 `current_todo.md`。

本地草稿命令在分派时读取当前阶段，不按每次设点都会变化的 revision 拒绝后续点击。队列、会话 owner 和模式负责隔离旧输入。两次点击可以在同一 tick 建立完整范围，第三次点击按完成后的阶段处理。

## 待完成的迁移约束

- 将物理输入转换为带按钮、动作、修饰键、手势和环境身份的语义事件。
- 先发布只读输入归属，再让回调即时决定原版拦截。保留滚轮移动失败时的当前让行行为。
- 在同一队列中保持 Enter、Q、按下、释放和滚轮的顺序，不能仅迁移滚轮。
- Cancel 当前会清理路由请求身份。已发送请求的取消和恢复仍须由提交 owner 持有，不能把路由进入 IDLE 当成服务端已撤回。
- 用入口测试检查拒绝事件不会改变草稿、预览版本或请求归属。本表本身不构成测试证据。
- 选区 D3 已确认：设点和范围编辑仍是选区，变换改变方块集合后才成为部件，集合恢复相同时变回选区。实现和验收按此规则继续迁移。
