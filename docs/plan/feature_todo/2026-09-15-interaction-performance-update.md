# 交互优化更新

## 目标

通过算法和工程优化，使快速起形、选区编辑和连续交互在大型输入下保持流畅。
不得只改变阈值、降低预览细节或延迟反馈来换取表面上的流畅。

## 工作范围

- [ ] 优化形状扫描和方块生成算法，避免重复扫描、重复装箱和无效中间集合。
- [ ] 优化预览缓存换代，使新候选逐步接管显示，并拒绝过期异步结果。
- [ ] 将外壳部件准备、网格生成和 GPU 上传纳入可测量的分帧预算。
- [ ] 复用稳定的数据和缓冲区，降低连续移动时的对象分配、复制和垃圾回收压力。
- [ ] 按结构表面积和实际渲染成本分配详细预览预算，不只按包围盒体积设置固定阈值。
- [ ] 建立性能基准，记录输入到首帧、完整预览时间、帧耗时、内存峰值和实际显示方块数。

## 验收原则

- 半径约 20 格的球体连续调整时，客户端不应卡死或出现明显长帧。
- 新候选必须立即提供正确反馈，详细预览可以渐进补全。
- 提高预览规模上限前，必须先满足帧耗时和内存预算。
- 阈值只用于保护资源，不能代替算法优化。
