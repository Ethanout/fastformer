# 选区阶段迁移记录

## 草稿事件转换

草稿事件保存按钮、不可变目标点和 Alt 修饰。控制器保留提交门禁、部件生成及撤销记录；选区会话统一推进草稿。

| 模式与阶段 | 事件 | 草稿动作 | 结果 |
| --- | --- | --- | --- |
| 任意 | 非法按钮或空目标 | 不修改 | REJECTED |
| cuboid | 左键 | 重设第一点，清除旧范围扩展 | UPDATED |
| cuboid 无首点，普通 | 右键 | 保留当前无操作行为 | REJECTED |
| cuboid 无首点 | 中键，或 Alt 右键 | 设置首点 | UPDATED |
| cuboid 一个点 | 普通右键或中键，Alt 右键 | 设置第二点 | READY |
| cuboid 少于两点 | Alt 中键 | 添加当前点，不生成部件 | UPDATED |
| cuboid 两点已有 | Alt 中键 | 仅扩大 min/max，不改输入点 | UPDATED，无变化则 REJECTED |
| cuboid 两点已有 | Alt 右键 | 重设第二点并重新计算边界 | READY |
| prism 有点 | 普通或 Alt 左键 | 删除最后一点；删除到底面内时重新开放底面 | UPDATED |
| prism 无点 | 普通或 Alt 左键 | 不修改 | REJECTED |
| prism 底面至少三点且未闭合 | 右键精确命中首点 | 固定底面点数，不重复添加首点 | UPDATED |
| prism 未闭合 | 其他右键或中键 | 添加底面点 | UPDATED |
| prism 已闭合 | 右键或中键 | 添加高度点 | READY |

READY 不清理草稿，也不自行读写世界。只有控制器成功生成部件后才清理草稿。结果不合法或部件生成失败时仍保留草稿。

## 待定项的现有行为

- D3 的迁移前行为：普通 cuboid 完成两点后立即尝试生成部件；Alt 中键两点后继续保留草稿供扩展。2026-09-19 用户明确替换此规则：设点和范围编辑仍是选区，改变方块集合的变换才使其成为部件，集合恢复相同时变回选区。控制器与显示入口仍需迁移，不能将旧生成行为当作目标。
- prism 底面至少三点，当前闭合判断是与首点方块坐标相等。高度点在闭合后添加。
- Alt 退出阶段优先级当前为：仍持有 Alt、存在草稿、存在选择集、未选中。后续状态机迁移不得无依据改变优先级。
- `CONVEX_HULL` 存在于枚举但不在当前模式轮换中；普通草稿入口拒绝，Alt 入口沿用 cuboid 编辑路径。其独立设计仍未定义。

## 本次明确规则迁移

- Alt prism 不再将左键当成添加点，也不再拒绝中键；按伪代码与普通 prism 共用撤点、底面和高度规则。
- Alt cuboid 两点后的右键重设第二点，不追加第三个输入点。重新设点清除旧扩展。
- 非法事件在选区会话内拒绝，控制器不再为被拒绝的事件清除选择集。

## 归属

- 转换规则由 `SelectionDraftTransitionTest` 覆盖。
- 草稿、部件和选择集归 `ClientSelectionSession` 持有。阶段查询只读计算，不写入缓存阶段。
