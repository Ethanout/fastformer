# 外框变换顺序复核

## 确认的代码差异

`WorkspacePreviewComposer.resolveCore` 先旋转，再加平移。`WorkspaceSelectionBounds.rotatedCuboid` 先调用已经加平移的 `axisAligned`，随后绕几何帧中尚未平移的中心旋转。几何帧存在且旋转与平移同时非零时，两条路径不等价。

例如，绕 Y 轴旋转 90 度，再沿 X 轴平移 10 格。方块中心应增加 `(10, 0, 0)`。现有外框路径却把该平移量也旋转为约 `(0, 0, -10)`。这是顺序错误，不是体素取整误差。

另一个差异：外框 `scaledExtent` 使用 `Math.rint`，体素缩放使用 `Math.round`。尺寸乘积为 2.5 时，前者得到 2，后者得到 3。

## 集中修复方向

让外框与体素共享变换顺序及舍入规则。外框先在未平移坐标中执行缩放、重复、旋转，再统一平移。保留含空气的选区范围，并检查缩放中心与选区中心不同的情况。

回归测试需覆盖：旋转加平移、多轴旋转、2.5 舍入边界、偏置空气选区、零旋转和零平移。用独立预期坐标判断结果，不能用同一错误函数生成预期值。
