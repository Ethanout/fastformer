# 外框变换消费者补修

主代理检查实际代码后修正三处遗漏：

- 无旋转 cuboid 路径原先传入 null frame，缩放与重复时没有使用体素流水线的锚点和步距。现在使用实际 frame。
- `resolveBase` 的备用路径原先重新读取部件完整 transform，忽略已经计算的 `withoutRepeats`。现在解析传入的 transform。
- 外框消费者原先每次重新生成 frame。完整变换现在复用 `frameForPart`，无几何变化的平移直接跳过 frame。去除重复的基础包围盒仍独立计算，以免误用完整重复后的旋转中心。

缓存容量与保留数据预算仍由单独修复处理，不能把消费者接入缓存视为性能审计完成。后续需要真实部件的稀疏选区缩放测试与客户端性能验收。
