# 缩放外框与方块的半整数取整不一致

类别：程序逻辑、交互外框一致性。

`WorkspaceSelectionBounds.scaledExtent` 使用 `Math.rint`，方块合成使用 `Math.round`。5 格宽内容的缩放系数为 0.5 时，方块宽度为 3，外框宽度为 2。外框可因此小于内容，并影响依赖外框的交互尺寸。

修复将外框改用与方块合成一致的 `Math.round`。保留原有最小尺寸和非法缩放处理。

新增测试比较 0.5、0.9、1.3 三个缩放系数下的方块边界与外框边界。测试在修复前失败，修复后通过。外框、旋转框架与稀疏缩放测试一起通过，构建耗时 9 秒。

证据范围：已证明变换模型的计算不一致，尚未通过实际游戏手势复现。普通棱柱拖动使用整数目标宽度，不能将本测试描述为所有拖动都会触发。稀疏选区尺寸与占用尺寸的语义差异仍需独立处理。
