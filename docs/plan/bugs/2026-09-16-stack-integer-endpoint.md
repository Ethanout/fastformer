# 重复区域枚举的整数端点溢出

类别：底层逻辑边界。

`OperationStackRegion.repetitions` 使用 int 循环变量。端点为 `Integer.MAX_VALUE` 时，递增会回绕到最小整数，继续枚举范围外坐标。单格区域调用 `repetitions(2)` 即可复现错误输出。

修复使用 long 遍历已知的 int 坐标区间，仅在构造位置时转回 int。三个轴的最大整数单格边界均有回归测试。修复前测试失败，修复后整个 `OperationStackRegionTest` 通过，构建耗时 10 秒。

普通拖动受 ±128 限制，尚未证明它能触发该端点。本修复不解决大规模重复的提前分配和几何预算问题，这些仍需后续架构调整。
