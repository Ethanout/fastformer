# 大文件职责审计

## 已确认的维护风险

- `FastPlaceClientPreviewCore.java`：3878 行、约 245 个方法声明，同时管理世界预览会话、建筑缓存、异步生成、工作区预览和反馈状态。
- `FastPlaceClientInput.java`：2707 行、约 128 个方法声明，同时路由键鼠输入、双击路径、操作拖动、近距离原版操作和提交按键。
- `FastPlaceManager.java`：1217 行、约 73 个方法声明，同时管理服务端会话、预览、提交、租约和恢复队列。
- `ClientOperationController.java`：1185 行、约 76 个方法声明，同时管理工作区、剪贴板、提交状态、失败恢复、断线草稿和源方块遮罩。

## 安全拆分方向

1. 先为 `FastPlaceClientPreviewCore` 抽出无状态的缓存生命周期协调器和预览会话状态投影。保留现有公开入口，逐步委托，避免改变渲染顺序。
2. 从 `FastPlaceClientInput` 抽出操作拖动路由、路径双击状态和原版近距离路由。每个对象只接收已经解析的输入上下文，不直接读取全局 Minecraft 状态。
3. 从 `FastPlaceManager` 抽出租约生命周期和恢复队列。服务端写入顺序必须保持在同一主线程边界内。
4. 从 `ClientOperationController` 抽出提交事务和草稿存储适配器。失败目标、源遮罩和交互状态仍由控制器统一投影。

## 约束

拆分前先增加行为契约测试，再逐段委托。禁止把静态字段复制到新类，禁止改变输入优先级、提示键或网络包顺序。该文件记录审计结果，不表示拆分已完成。
