# 旋转外框与平移顺序

## 原因与修复

`WorkspaceSelectionBounds.rotatedCuboid` 原先先平移外框，再围绕未平移的旋转中心旋转。方块合成则先旋转，再平移。因此同时旋转和平移时，外框与方块会发生额外偏移。

修复先以零平移生成旋转前的外框，沿几何帧的旋转步骤处理八个角点，最后对角点施加平移。缩放、重复与旋转中心的既有选择保持原语义。

## 验证

新增 `RotationFrameContractTest.translationMovesTheRotatedEnvelopeWithoutRotatingTheDisplacement`。用例覆盖单轴四分之一圈和多轴旋转，使用非零三轴平移。断言平移前后外框的六个边界只改变指定距离，同时对照实际合成方块的占用范围。

格式检查、旋转定向测试与随后完整单测通过。完整单测为 1292 项，0 失败、0 错误、1 跳过。此修复不代表旋转预算、方块状态旋转和缩放取整问题已经解决。
