# 预览网格失败后的恢复

日期：2026-09-16。R5 修复通过定向测试。

原问题：网格构建失败后，缓存保留输入但丢弃任务。相同输入不会再提交，预览持续为空。

当前实现使用失败状态和 50 至 800 毫秒退避，在后续预览请求中重试。同步失败、异步失败和提交被拒绝均可重试。合法空结果不重试。换输入或清空预览会取消旧任务并清除重试状态。

主代理补充：当前任务取消后也安排重试。纳秒时钟使用差值判断截止时间，避免计数溢出导致提前重试。同一输入持续失败只记录首次异常，成功或换输入后重置。

验证：PendingGhostMeshCacheTest 共 12 项通过，无失败或跳过。覆盖暂时失败恢复、持续失败退避、清空、换输入、旧任务晚到、同步失败、提交拒绝、合法空结果，以及取消与时钟溢出。`git diff --check` 通过。仍需实机验证预览显示。
