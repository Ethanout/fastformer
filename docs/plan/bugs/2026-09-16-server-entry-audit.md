# 服务端入口复核

## 快速替换首次调用空指针

- 状态：代码已修复。`gradlew test --console=plain` 在本次修改后重新编译并执行测试，28 秒完成，BUILD SUCCESSFUL。尚无首次快速替换的专用回归测试，游戏验证仍待进行。
- 位置：`QuickReplaceManager.replaceCrosshair` 的同 tick 去重。
- 触发：玩家首次通过快速替换前置检查，去重 Map 尚无该玩家记录。
- 原因：`Map.put` 返回 null，随后与 long 比较时自动拆箱，抛出空指针异常。异常发生在射线和世界写入前。
- 修复：保存可空的上一 tick，仅在非空时比较。首次请求继续执行，同 tick 重复请求仍被拒绝。

## 仍需修复的架构问题

- 玩家换维度仍调用 `FastPlaceManager.quit`，与保留会话和已提交任务的设计原则冲突。需要按维度保存编辑状态，并把环境解绑与用户取消分开，不能仅删除 quit 而把旧维度坐标用于新维度。
- 快速替换恢复旧快照时仍忽略恢复结果。应统一短事务执行与恢复接管，保留失败快照，明确区分不适用、失败已恢复和恢复中。详细方案见 `2026-09-15-architecture-transactions.md`。
