# 交互设计语言

本文定义输入、视觉和体感的一致规则。阶段细节属于当前代码实现，不在多个文档重复维护。

## 输入归属

- 创造模式且功能开启时，双击右键或 Alt+右键进入起形／选区。长方体双击的第一击只保存交互快照，第二击进入会话并设点1；Alt+右键也设点1。空会话普通点击交给原版。
- 空会话起形入口：Alt+右键取普通表面放置位置；Alt+中键嵌入命中位置并提前提交首点。该区分不修改活动会话的输入规则。
- 超出玩家当前 `block_interaction_range` 时，空会话右键／中键入口无需 Alt，扳手不生效。范围内保留原版点击和双击入口。
- 活动会话接管输入，与距离无关。范围内优先处理空手扳手，Alt+右键绕过扳手。其他模组先取消事件时，FastFormer 放弃抢占。
- 取消手动／自动控制、近远距离交接和 `/ff tinker reach`。
- 双击间隔暂定不超过200ms；第二击射线直接检测第一击生效前的形状快照，忽略世界方块遮挡。命中快照后，视线变化不超过2°或快照命中点间距不超过1/2格，满足任一条件即可进入会话。角度、距离和时间阈值均待实测打磨。判定失败时按当前世界重新处理第二次普通右键，并将其作为新的第一击。
- 扳手第一击立即生效。有效双击命中点击后的快照形状时，恢复第一击前的完整状态。全部还原位置先同步给客户端，再确认选区入口，形状读取还原后的状态。
- `/ff reach [<整数>]` 直接设置或查询原版方块交互属性，基础值默认20格。有效距离由原版属性及修饰器决定。
- 客户端负责草稿、工作区、选择集、本地撤回、Gizmo 命中、预览、源方块留影、待删除标记和剪贴板。
- 拖动只更新客户端状态。Enter 一次提交整个工作区。
- 服务端负责权限、维度、限制、来源校验、目标快照和原子世界写入。

## 选区语义

- `POINTING` 表示正在设置新选区点或等待服务端选区完成。
- `FOCUSED` 表示工作区存在选中部件。`UNFOCUSED` 表示工作区有部件但没有选中部件。
- `ALT_FOCUSED` 优先于其他选区状态，只处理 Alt 新建路径。
- AABB 使用两点模型。棱柱使用独立的多点模型。
- `point1` 和 `point2` 只记录最近设置的点。扩展不能修改它们。
- CUBOID 右键顺序填充点1、点2，左键撤回上次选点；中键填空缺点或扩展最晚选区。智能选区保留左键减选。PRISM 用右键加点，靠近首点时右键闭合，左键删除最后一个草稿点。
- Alt CUBOID 的中键规则是第一点、第二点、`expandTo(point)`。Alt 路径不让旧选区、部件选择、原版放置或快速起形抢占。
- 2026-09-19 用户确认例外：Alt + 左键／右键直接命中 Gizmo 时，变换命中的旧部件或公共选择集，不新建草稿。松开 Alt 不改变已开始拖动的归属，其他 Alt 点击继续编辑新草稿。
- 2026-09-19 用户确认：已有选区的普通中键，只要输入归属选区就拦截原版选取方块。没有变化、没有落点或编辑校验失败也不让行；有效编辑仍按范围扩展规则执行。

## 工作区操作

- 普通点击只选中一个部件。Ctrl 点击追加或取消选择。Ctrl+A 全选，全部已选中时取消全部选择，保留选区。
- Ctrl+R 将已选中的选区绕 Y 轴旋转 90°，从上方看顺时针。Ctrl+F 沿最接近视线的坐标轴镜像翻转。
- 已处于飞行状态时，在 250ms 内双击前进键（默认 W），第二击保持按住即可快速飞行：从原版基础飞行速度的 2 倍平滑增加，3 秒达到上限 10 倍；起步和接近上限时平缓过渡，不再叠加原版疾跑倍速。松开、打开界面、失焦或退出飞行即取消。
- 多选时使用已选中选区整体边界的共同中心。快捷键只变换选择集，每次按下记录一个撤销步骤。
- Delete/Backspace 标记世界来源部件待删除，直接移除剪贴板来源部件。Ctrl+Delete 移除选中部件，不修改世界。
- Ctrl+C 复制当前预览。Ctrl+V 只创建本地部件，不立即写世界。Ctrl+D 在原位置复制选中部件，保留形状和变换参数，只选中新副本，不修改剪贴板。
- MOVE 沿轴移动。STACK 按整数区间重复。ROTATE 绕部件中心或公共中心旋转。SCALE 对棱柱改尺寸，对其他部件使用 repeat 语义。
- Enter 提交非空工作区。Ctrl+Z 优先撤回客户端工作区，再请求世界撤回。Q/Esc 取消当前会话或任务。

## 视觉语言

- 以 [2026-10-01 视觉规范](../visual-style.md) 为准。经典与人文主题共用白色主线，用透明度区分候选和已确认。
- 颜色从主题资源读取。起形预览显示目标方块模型，线条以外轮廓为主。
- 人文主题使用铅笔笔触，仅动态部分抖动。Gizmo 的 XYZ 颜色只表示轴。
- 方块外框统一外扩 `OUTLINE_INFLATE`。标签是浅纸底配深墨字。界面文字和面板用中性灰白，暖色只用于有含义的状态。
- 视觉包围盒不扩大交互命中盒。超出上限时保留边界和操作方向。
- 活动会话中的 Alt 准星沿用嵌入模式的 X 形反馈。空会话按住 Alt 不自动表示嵌入。后处理不可用时使用可见 GUI 回退。
- 新部件创建成功后只选中新部件，其他部件降低透明度。预览始终响应当前世界。

## SmartWoodFrame

`SmartWoodFrame` 为每条棱计算归一化方向。单棱方块继承棱轴。角点比较关联棱的 XYZ 绝对分量。它不是只保存三个轴响应。

## 选区确认兼容字段

服务端 `OperationSession.selectionConfirmed` 表示进入选区后的变换阶段。`OperationTransformState.adjustmentStarted` 表示变换编辑已经开始。

2026-09-19 用户确认的 D3 规则替换“ready 后成为部件”的旧规则。收到 ready、设点、修改范围或按 Enter 都不使选区成为操作部件。只有变换后的完整方块集合不同于固定原集合时，选区才成为部件。恢复原集合后恢复选区身份、编辑能力与显示。比较包括世界位置、方块状态和方块实体数据，hash 相同时仍核对完整集合。

网络 payload 的 `operationSelectionConfirmed()` 是旧名称的兼容访问器，实际返回 `adjustmentStarted`。它不是独立的 Enter 事件，也不能作为选区与部件身份的依据。迁移中的输入和渲染入口必须区分这个兼容字段与 D3 身份。规则来源见 `../pseudocode/sessions/10-选区.md`。
