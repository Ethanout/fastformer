# 方块扳手设计表

版本：Minecraft 1.21.1。操作均指创造模式空手右键。本表规则已实现；后续改动以本表为设计依据。

现有实现说明见 [方块扳手](方块扳手.md)。本表中的新决定优先，实施后再同步实现说明。

## 共同原则（已确认）

- 点击看到的面的某个部分，就让那个部分响应；命中模型部位优先于单纯点击面方向。
- 不切换含水。不因编辑补水或排水；类型转换保留兼容的含水状态，目标不能保留时不静默丢失水。
- 侧面较难点到时，将点击位置到相邻侧面的距离不超过 1/8 格的区域作为边缘带（原版 16 像素材质的 2 像素）；边缘带外执行当前面的内部操作。多个边缘带重叠时取距离最近的侧面，等距时保留当前命中面的操作。专门规则优先。
- 创造模式无需保留吃蛋糕、取骨粉、采摘等获取资源的手段；编辑命中后可屏蔽原版消费／产物行为，不额外产生资源。容器界面和普通开关不因此全部屏蔽。
- 加减操作到上下限停止，不减到删除；明确写“循环”的类型转换首尾相接。
- 未明确修改的属性保留，世界修改可撤销。保留物品和方块实体数据，本轮不伪造有书、有唱片、有瓶子等镜像状态。
- 未确认项中，未明确写出转向操作的，默认不允许改变朝向、轴向或旋转角度；已明确填写的转向方案保留。
- 材质族、属性规则尽量共用并由数据包配置；形状分组只辅助归类，不自动决定操作。
- 普通点击保留原版容器界面；下蹲执行已明确允许的转向。专门的面操作优先，例如熔炉正面切换燃烧外观。
- 邻居或 tick 会改变的状态仍允许编辑，不为此禁止操作；编辑本身不产生资源。
- 多种操作按命中的可见部位分配，形态操作优先；下蹲覆盖规则以各方块族的说明为准。
- 多格结构只在操作要求时联动：门、箱子连接、活塞联动；高草等已明确的单格编辑保持单格。
- 开启“不通知邻居”时，创造模式直接破坏门、床、双格植物或活塞，只移除命中的那一格，保留未命中的部分及其状态；客户端预测与服务端使用同一更新策略。扳手明确要求的多格编辑仍按表中规则联动。
