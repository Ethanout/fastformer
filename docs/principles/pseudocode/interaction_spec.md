# 顶层交互树

本文只描述玩家会话树的结构和含义。

本文不描述 Java 类、字段、网络格式、线程或方块算法。

用户修改本文后，本文成为顶层交互语义的权威版本。

## 会话树

```text
player
├── session
│   ├── empty
│   ├── quick_shape
│   │   ├── entrance
│   │   ├── point0
│   │   └── A
│   │       ├── point
│   │       ├── line
│   │       ├── face
│   │       └── volume
│   ├── special_shape
│   │   └── stage
│   └── special_item
├── selection
│   ├── pointing
│   ├── focused
│   ├── unfocused
│   └── alt_focused
├── operation_workspace
│   ├── parts
│   ├── selected_parts
│   ├── transform
│   └── clipboard
└── lifecycle
    ├── connected
    ├── world_changed
    └── awaiting_snapshot
```

`session` 的四个子节点互斥。`A` 是 `quick_shape` 的主工作层，不是第五种会话。

`selection` 和 `operation_workspace` 是共享层，不参与会话互斥。

## 盒子与节点

每个节点保存自己的值、子节点、signal 处理器和进入/退出动作。

节点只处理自己的状态和动作。切换时先退出旧节点，再进入新节点。

节点切换不清空盒子。完成、取消或显式清理才删除节点内容。

## inspect

`inspect` 只读取当前节点到根节点的路径，表示状态树的当前位置。

`inspect` 不保存第二份状态，也不触发状态转换。

## signal

玩家操作先转换为带名称和载荷的语义 signal，再交给当前节点。

当前节点只调用自己的处理器。未注册的 signal 不产生动作，也不冒泡。

处理器可以更新当前盒子或请求节点切换。

```text
player input
  -> semantic signal
  -> current node handlers
  -> node-owned state and preview
  -> optional node transition
```

## 玩家

玩家是整棵树的宿主。

玩家盒子保存会话、选区、工作区和生命周期状态。

玩家对象重建时，玩家盒子不重建。

玩家重生、换维度或重新连接时，玩家盒子不清空。

玩家会保存所有会话的上次模式。

## 会话

`session` 表示玩家当前使用的主要功能。

四个会话节点互斥。任意时刻只有一个会话节点处于活动状态。

### empty

empty 表示玩家当前没有运行中的 FastFormer 会话。

- 手持方块远距离右键：进入 `quick_shape`，传入入口来源和右键点
- 手持特殊物品：进入 `special_item`，会话类型由物品决定
- 空手近距离点击方块：交给类似 Axiom 扳手的行为
- 空手远距离操作：交给选区逻辑

### quick_shape

quick_shape 表示玩家正在使用快速起形。

- 处理快速起形阶段、选区草稿和候选预览
- 工作区已有部件时，Alt 新建由 `selection` 层接管
- 只有明确退出才销毁草稿
- 不销毁内部选择模式，下次进入继续使用
- Enter丢弃预备点，并直接放置
- 中键确定预备点，并直接放置（除非声明不允许）
- 左键表示回退，右键表示新点/确认

#### 进入

```text
enter(entrance, point=None):
    if entrance == empty and point exists:
        session = quick_shape
        session.set_state("line")
        session.point0 = point
    else:
        session = entrance
```

从 `empty` 带着右键点进入时，右键点就是 `point0`。

#### line（确定线）

点1已经确定，根据当前模式确定点2，未确定的点2称为预备点2。
一共有：
- 横平竖直
    - 按住Alt：
        - 吸附为坐标平面
        - 十字准星进入选择平面动画
    - 否则吸附为横平竖直
- 视线落点
    - 按住Alt：
        - 视线落点嵌入方块
        - 十字准星进入旋转45度动画
    - 否则选中表面
- 滚轮

模式切换 -> 滚轮：
保留切换模式时预备点2的偏移。例如点1为(1,1,1)，预备点2为(1,2,3)，滚轮初始偏移为(0,1,2)。

滚轮只改变候选偏移，不设置或修改点1、点2。

#### face（确定面）

点2已经确定，根据当前面模式确定点3或更多点。

一共有：
- 坐标平面
    - 吸附到包含点1、点2的坐标平面
    - 视线落点只决定平面内的候选点
    - 中键直接将点3确定并提前确认跳出
- 基准面
    - 生成点1、点2确定的平行四边形基准面
    - 滚轮调整基准面偏移，滚轮向上远离视线，向下靠近
    - 中键直接将点3确定并提前确认跳出
- 多边面
    - 右键添加面点
    - 靠近第一个点时再次右键闭合
    - 左键删除最后一个面点
    - 中键无行为
- 面完成后进入体阶段

#### volume（确定体）

体阶段根据已确认的面和当前体模式计算候选体。

一共有：
- 垂直于面
    - 沿已确认面的法线方向确定高度
    - 视线落点决定预备高度点
- 自由
    - 滚轮调整体偏移
    - 预备高度点跟随偏移变化

按键：
- 左键
    - 按当前体流程回退
- 右键
    - 设置高度点或确认当前阶段
- Enter
    - 候选体完整且未超过上限时确认

#### 十字准星特殊动画
不同入口暂时使用同一个动画实现。

## special_shape

special_shape 表示玩家正在使用特殊形状流程。

- 按点、线、面和体推进
- 只有明确退出才销毁草稿
- 不销毁内部选择模式，下次进入继续使用
- 右键：推进或确认当前阶段
- 左键：按形状流程回退
- Enter：使用已确认的形状状态
- 滚轮：只调整当前阶段声明的参数

## special_item

special_item 表示玩家正在使用特殊物品。

- 只处理特殊物品声明的交互
- 只有明确退出才销毁动作草稿
- 不销毁内部选择模式，下次进入继续使用
- 完成或取消：回到 `empty`

## operation_workspace

`operation_workspace` 是共享工作区，不是第五种会话。

- 保存独立部件、部件选择、变换状态和剪贴板
- 快速起形或特殊形状完成后，接收完整候选部件
- 只显示工作区覆盖层和 Gizmo，不显示原始选区副本
- 支持移动、旋转、缩放、重复、复制、删除、多选、撤回和提交
- 不限制部件数量，不使用 Ctrl 加数字槽位

## 选区

`selection` 表示玩家当前的选区工作。

选区可以在快速起形和工作区之间保存。

- 选区草稿、已确认选区和工作区部件是不同对象
- 编辑草稿不能隐式修改已确认部件

### pointing

- 左键或右键设置 `point1`、`point2` 或其他控制点
- `minPoint`、`maxPoint` 是当前 AABB 的唯一边界
- Alt 加中键只改变 `minPoint`、`maxPoint`
- 扩展不能修改 `point1`、`point2`
- 预览使用边界，但不把边界反写成点

### focused

- 工作区存在选中的部件
- 移动、旋转、重复、复制、删除、多选、撤回和提交可用

### unfocused

- 工作区存在部件，但没有选中的部件
- 点击部件、标签或边框：选中部件

### alt_focused

- 按住 Alt：当前选区和已选部件降低透明度，进入 `alt_focused`
- Alt 只改变输入焦点，不清空旧选区
- 左键或右键：创建、添加或闭合新选区草稿
- Alt 状态不编辑旧选区或已选部件
- 中键：按选区模式设置第二点或扩展新草稿
- 旧选区、部件选择和原版放置不能抢占 Alt 输入
- 松开 Alt：按草稿状态回到 `pointing`、`focused` 或 `unfocused`

## lifecycle

- `connected`：玩家身份建立，可以接收输入和权威快照
- `world_changed`：只更换运行环境，不删除会话、选区、工作区和模式
- `awaiting_snapshot`：等待新环境的活动权威快照
- 暂时的空快照不表示取消
- 已提交的世界任务不因重生、换维度或断线停止
