# 快速起形
[返回会话树](README.md)

```text
快速起形 quick_shape:
    用途: 点 -> 线 -> 面 -> 体
    数据:
        当前阶段
        已确认点
        候选点、候选参数
        上次模式
        已确认数据 != 正在计算的候选 != 当前显示的预览

    进入(入口, 点):
        如果 入口 == 空闲 且 点存在:
            point0 = 点
            -> 主流程.线
        如果 收到属于当前玩家的活动权威快照:
            -> 快照中的阶段与模式
        否则:
            待定(其他入口)
    显示:
        当前形状候选、控制点、引导线、阶段提示
        不同入口的准星动画暂用同一实现

    主流程:
        点 point:
            待定(与入口、point0 的区别)

        线 line:
            已确认: 第一点
            候选: 第二点
            模式:
                横平竖直:
                    鼠标 [未按 Alt]: 沿坐标轴吸附
                    鼠标 [按住 Alt]:
                        吸附坐标平面
                        准星显示选择平面动画
                视线落点:
                    鼠标 [未按 Alt]: 选方块表面
                    鼠标 [按住 Alt]:
                        落点嵌入方块
                        准星旋转 45 度
                滚轮:
                    进入模式:
                        保留当前候选相对首点的偏移
                        例: (1,2,3) - (1,1,1) = (0,1,2)
                    滚轮:
                        只改候选偏移，不改已确认点
            输入:
                右键:
                    确认线
                    -> 面
                左键:
                    删除首点，回到首点入口
                Enter:
                    执行本页 Enter 提交规则
                    滚轮模式保留第二点候选，确定线并提交
                    其他模式丢弃第二点候选，只提交已确认部分

        面 face:
            已确认: 前两点、线
            候选: 第三点或更多面点
            输入:
                Enter: 执行本页 Enter 提交规则
            模式:
                坐标平面:
                    鼠标:
                        吸附包含前两点的坐标平面
                        视线只决定面内候选点
                    右键: 确认面点
                    左键: 删除第二点，回到线阶段
                    中键:
                        确认第三点，提前确认
                        立即写入世界，结束本次起形
                基准面:
                    候选: 前两点确定的平行四边形基准面
                    滚轮向上: 基准面远离视线
                    滚轮向下: 基准面靠近视线
                    右键: 确认面点
                    左键: 删除第二点，回到线阶段
                    中键:
                        确认第三点，提前确认
                        立即写入世界，结束本次起形
                多边面:
                    右键 [未靠近首点]: 添加面点
                    右键 [靠近首点]: 闭合
                    左键: 删除最后一个面点
                    中键: 无操作
            面完成:
                -> 体

        体 volume:
            已确认: 面
            候选: 高度点、体偏移、候选体
            模式:
                垂直于面:
                    沿面法线确定高度
                    视线决定预备高度点
                自由:
                    滚轮调整体偏移
                    预备高度点跟随偏移
            输入:
                左键: 执行本页回退规则
                右键: 设置高度点或确认阶段，具体条件待定
                Enter:
                    执行本页 Enter 提交规则


    输入设计约定:
        本段列共同语义，不是父节点冒泡处理器
        每个活动阶段需要明确注册允许的事件
        左键 / 会话内 Ctrl+Z: 执行本页回退规则
        右键: 新点或确认，不等于立即写世界
        中键: 通常确认预备点并提前放置，阶段可禁用
        Enter: 执行本页 Enter 提交规则
        Alt [已有选区部件]:
            作为信号使用
        Q / Esc:
            未发送: 取消本地会话
            已发送: 走任务取消或恢复，不提前显示已撤回

    退出:
        明确退出才销毁本会话草稿，停止候选预览
        保留上次模式、共享剪贴板、非本次取消的部件
        切换或临时空快照 != 明确取消

    Enter 提交规则 (2026-09-20 用户确认):
        数据来源:
            默认丢弃预备点，只提交已确认部分
            如果阶段或模式专门设置了按键行为，按专门规则执行
            当前唯一例外是滚轮模式：Enter 不丢弃预备点
            使用滚轮调整参数不自动构成例外，必须是明确的滚轮模式
        校验与提交:
            完整性和限制检查只针对上述规则确定的提交数据
            不用被丢弃的候选点补全形状
            数据满足提交条件且未超限：记录并压缩，写入世界，加入任务堆栈
            超限：显示信息超出限制，不提交
        计算中的等待和重试行为:
            按 Enter 时固定按上述规则选出的提交数据，创建一次提交意图
            数据仍在计算：等待本次数据计算与校验完成，再自动提交一次
            等待期间不接受形状修改，不用后来的候选或旧显示替换提交数据
            重复 Enter 不创建第二次提交
            Q：取消尚未发送的提交意图，迟到计算结果不得发送
            校验失败：不发送；新的提交需要新的 Enter
            已发送：等待服务端结果，取消走任务取消或恢复流程

    回退规则 (2026-09-20 用户确认):
        每次删除最后一个已确认点，逐级回退，不提交世界写入
        普通面阶段：删除第二点，回到线阶段
        普通体阶段：删除第三点，回到面阶段
        多边面或多面体：每次撤回一个点
        已确认高度点：先删除高度点，保留闭合底面
        闭合底面且未确认高度：删除最后一个底面点，重新进入面阶段
        删除最后一个点后结束本次起形

    完成规则 (2026-09-20 用户确认):
        坐标平面与基准面中键确认第三点后立即写入世界
        多边面中键无操作，不设点，不提交，也不让给原版

    待统一:
        D6.取消:
            新形状与既有选区部件分别保留什么
```
