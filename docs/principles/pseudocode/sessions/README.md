# 会话树

运行方式见 [00-状态机](00-状态机.md)：状态自己判断退出原因，状态机统一切换。同一 tick 可以依次经过多个状态。

直接修改各页代码块中的缩进树。缩进表示归属，`->` 表示去向，`待定(...)` 表示尚未决定。不需要维护表格或画树枝符号。

```text
玩家:
    会话: 五选一
        空闲 empty:                  打开 01-空闲.md
        快速起形 quick_shape:        打开 02-快速起形.md
            入口 entrance
            首点 point0
            主流程 A:
                点 point
                线 line
                面 face
                体 volume
        特殊形状 special_shape:      打开 03-特殊形状.md
        特殊物品 special_item:       打开 04-特殊物品.md

        选区操作 selection:          打开 10-选区.md
            入口: Ctrl+V / 左键 / 中键 / 右键，先判断输入归属
            设点 pointing
            已选中 focused
            未选中 unfocused
            Alt新建 alt_focused

            部件与选择集
            变换
            提交与取消
            访问玩家共享剪贴板

    生命周期:
        connected: 接收输入和权威快照
        world_changed:
            更换环境，释放旧环境瞬时资源
            保留会话、选区数据、上次模式
        awaiting_snapshot:
            等待新环境权威快照
            临时空快照 != 取消
        已发送世界任务:
            不因重生、换维度、断线而停止
            退出本地会话 != 服务端取消完成

编辑约定:
    数据: 此节点保存什么
    显示: 玩家看到什么
    进入: 进入时执行什么
    输入:
        按键 [条件]:
            动作
            -> 下一节点
    退出: 删除什么，保留什么
    待定(...): 尚未设计，不是无操作
    无操作: 消费输入，不执行动作
    原版: 明确让给原版

共用规则:
    节点只处理已注册事件，不冒泡
    未注册事件 != 自动原版让行
    输入归属独立判断
    其他模组已取消的输入不抢占
    一般近距离鼠标交互 -> 原版，扳手路径另定
    inspect: 只读当前路径，不保存第二份状态
    切换: 先退出旧节点，再进入新节点
    节点切换不等于清空共享对象
    上次模式保留

待统一:
    D2: 特殊形状与其他完整候选的完成去向；快速起形中键完成规则已确认
    D4: 轮廓降级，还是保留上一份完整预览
    D5: 其他会话的精确回退目标；快速起形已确认逐点回退
    D6: 取消删除哪些草稿，保留哪些部件

已确认:
    D2 [2026-09-20]: 快速起形坐标平面／基准面中键确认第三点后立即写世界
        多边面中键无操作，见 02-快速起形.md
    D5 快速起形 [2026-09-20]: 左键类似会话内 Ctrl+Z，每次撤回一个点
        普通阶段逐级回退，多边面和多面体同样逐点回退，见 02-快速起形.md
    D1 数据来源 [2026-09-20]: 快速起形 Enter 默认丢弃预备点，只提交已确认部分
        专门按键规则优先，目前唯一例外是滚轮模式保留预备点
        各阶段统一引用 02-快速起形.md 的 Enter 提交规则
        数据计算中等待计算与校验完成后自动提交一次，Q 可取消未发送意图
    D3 [2026-09-19]: 变换改变完整方块集合才成为部件
        恢复原集合后变回选区
        Enter、ready、设点和范围编辑不触发身份转换
        详细比较与恢复规则见 10-选区.md
```

编辑入口：[空闲](01-空闲.md)、[快速起形](02-快速起形.md)、[特殊形状](03-特殊形状.md)、[特殊物品](04-特殊物品.md)、[选区](10-选区.md)、[模板](99-设计模板.md)。

本目录的伪代码是交互逻辑的权威依据，不是实现证明。代码、测试和其他说明必须遵循已确认的伪代码。公共规则见 [interaction_rules.md](../../interaction_language/interaction_rules.md)。发现冲突时先向用户提问。用户未回复时，可按合理方案继续实现，但必须在相关节点标明“暂定实现”，并记入 [待审阅设计问题](../../../plan/design_questions.md)。收到答案后同步修改所有相关节点，不保留互相矛盾的有效规则。暂定项不得覆盖已确认规则。原四页已备份迁移，旧 quick_shape 页的选区规则在“10-选区”。
