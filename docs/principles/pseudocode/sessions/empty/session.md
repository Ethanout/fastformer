# Empty 会话

## 目标

没有正在运行的快速起形、特殊形状、操作或特殊物品会话。

## 持有状态

- 当前玩家盒子中的共享工作区和剪贴板。
- 当前生命周期状态。

## 进入

当没有其他会话匹配当前活动快照时进入。

进入反馈：隐藏会话专属预览和工作区 Gizmo。

## Signal

```text
session.preview_ready:
  条件：预览属于快速起形、特殊形状或操作会话
  动作：交给对应会话
  转移：对应会话

pointer.primary / pointer.secondary / pointer.middle:
  条件：输入属于近距离原版交互
  动作：不消费输入
  转移：保持 empty
```

## 退出

进入其他会话时，不删除共享工作区和剪贴板。

## 不变量

- 不显示会话专属 Gizmo。
- 不抢占近距离原版输入。
- 不因暂时没有活动快照而删除玩家盒子。
