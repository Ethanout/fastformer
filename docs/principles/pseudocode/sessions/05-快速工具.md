# 快速工具：键盘绑定

本页对应 `assets/fastformer/fastformer/bindings/default/tools.json`。键盘规则由该文件定义；代码只提供操作与上下文字段。

- 空闲且可以使用工具：R 切换快速替换；交换副手键（默认 F）开始智能填充。Ctrl 不触发这两项。
- 快速替换：R 退出；Ctrl+Z／Ctrl+Y 先结束当前笔画，再撤销／重做。其他按键不进入后续 FF 键盘处理。
- 智能填充：预览就绪时，交换副手键或主键盘／小键盘 Enter 确认；等待期间吞掉这些键。Q 沿用会话取消。
- 松开与重复按键不重复执行上述操作。快速替换继续吞键，填充只吞确认键。

`@swap_offhand` 跟随原版交换副手键映射。物理键使用 `key.keyboard.*`。输入适配器同时提供两种名称，按绑定的优先级与具体性统一匹配，不分两次分发。`*/key` 表示任意键。

上下文包含会话、界面、玩家是否存在、是否允许空闲工具、填充是否就绪／可开始、按键的按下／松开／重复及修饰键。用户可按绑定 ID 覆盖键、优先级或启用状态；删除规则后不回退到旧硬编码规则。

`input_phase` 区分按键入队前的 `capture` 和消费队列时的 `dispatch`。填充开始绑定不限制这项字段，使开始操作在按下时立即生效；捕获成功后该按键不再入队。活动预览的捕获绑定只清掉原版交换副手的 click，并返回 pass；确认在队列阶段执行，避免同一按下同时开始和确认。其他工具默认键只在 `dispatch` 执行。

快速替换的其他输入也由同一默认文件定义：使用键按下开始笔画，松开结束；重复使用和客户端 tick 在原有可替换条件下继续笔画，否则结束；失去创造权限或关闭功能时退出。滚轮明确 pass 给原版，不进入其他 FF 会话规则。事件适配器保留工具所有权和原版取消结果两个独立事实。

填充预览的鼠标／滚轮所有权仍由现有模式能力阻断；其余起形、几何、选区和空闲操作树继续迁移，不能据此视为第 9 节全部完成。
