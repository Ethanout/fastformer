# 选区操作会话
[返回会话树](README.md)

```text
选区操作会话 selection:
    所属: 相对独立的操作会话，与其他活动会话互斥
    入口:
        Ctrl+V [输入归属 FastFormer]:
            校验剪贴板与落点
            校验成功:
                从剪贴板建立操作内容
                -> 本会话
                待定(粘贴后的初始阶段与选择集)
            校验失败:
                保持原会话，不丢失原有数据
                返回失败原因
        左键 / 中键 / 右键 [满足选区输入条件]:
            携带本次按键、修饰键与命中
            -> 本会话.设点
            按设点规则应用入口按键一次，不重复派发原事件
        已在本会话内:
            Ctrl+V: 执行粘贴，不重复进入会话
            Alt新建: 切换本会话内阶段，不新增会话
    数据:
        草稿 != 已确认选区 != 操作部件
        point1、point2: 最近设置的输入点
        minPoint、maxPoint: 当前 AABB 唯一边界
        部件: 内容、来源、变换
        选择集: 当前操作哪些部件
        新建草稿不是部件本身
        访问玩家共享剪贴板
    内容来源:
        Ctrl+V 从剪贴板建立操作内容
        接收完整候选部件
        世界选区: 由改变方块集合的变换交入，见 D3
        待统一(D2: 其他完整候选的交入动作)
    显示:
        选区预览、选择反馈、可用 Gizmo
        不显示已经交入部件的原始选区副本
    约束:
        编辑草稿不隐式修改已确认部件
        普通选区输入: 创造模式 + 功能开启 + 远距离输入归属
        expandTo: 只扩大边界，不改输入点
        普通中键 [已有选区且输入归属本会话，2026-09-19 用户确认]:
            接管本次按下与释放，不执行原版选取方块
            有合法落点且允许编辑: 扩大选区范围
            无变化、无落点或校验失败: 不修改选区，仍拦截原版
        重新设点: 重算边界，清除旧扩展
        预览读边界，不反写输入点
        无固定部件数量限制
        不使用 Ctrl + 数字槽位

    设点 pointing:
        显示: 草稿点、候选边界
        模式:
            CUBOID:
                左键: 设置第一点
                右键 / 中键: 设置第二点
                普通中键 [无第一点，2026-09-20 用户确认]: 不设点，等待左键
            PRISM:
                右键 [未靠近首点]: 添加底面点
                右键 [靠近首点]: 闭合底面
                左键 [有草稿点]: 删除最后一点
                中键:
                    添加点或高度
                    待定(阶段条件)
        完成:
            D3 [2026-09-19 用户确认]:
                设点、修改范围等操作选区本身的行为: 仍是选区
                不因 ready、选中或按 Enter 就成为部件
                只有拖动、stack、旋转等改变方块集合的变换才使其成为部件
                拖动、stack、旋转等变换:
                    固定变换前的原始选区与方块集合
                    结果方块集合不同于原始集合: 成为部件
                    结果方块集合相同: 保持选区
                部件经过后续变换:
                    结果方块集合与原始集合相同: 变回原始选区
                    否则: 保持部件
                比较依据:
                    完整方块集合，不使用肉眼、边框或变换参数判断
                    比较世界位置、方块状态与方块实体数据
                    可先比较 hash，hash 相同时仍核对完整集合
                    使用固定的原始集合，不重新读取正在变化的世界
                交入部件后: 不再显示原始选区副本
                变回选区后: 恢复选区编辑能力与原始选区显示

    已选中 focused:
        条件: 选择集非空
        显示: 部件选择反馈、可用变换
        输入: 按本会话的部件操作规则处理

    未选中 unfocused:
        条件: 有部件，选择集为空
        显示: 可选择的部件、标签、边框
        点击部件 / 标签 / 边框:
            选中
            -> focused

    Alt新建 alt_focused:
        例外 [2026-09-19 用户确认]:
            Alt + 左键 / 右键 [直接命中 Gizmo]:
                变换命中的旧部件或公共选择集，不新建草稿
                按下时固定目标、按钮、修饰键与手势身份
                松开 Alt 不改变已开始拖动的归属
        进入:
            输入焦点交给新草稿
            旧选区、已选部件降低透明度，不清空
            保留原选择集，仅转移输入焦点 [2026-09-20 用户确认]
        模式:
            CUBOID:
                中键 [无第一点]: 设置第一点
                中键 [有第一点，无第二点]: 设置第二点
                中键 [两点已有]: expandTo
                左键 / 右键: 只编辑新草稿
            PRISM:
                左键 / 右键 / 中键: 只编辑新草稿，按模式处理
        约束:
            除直接命中 Gizmo 的例外外，不编辑旧选区、已选部件
            旧选区、部件选择、原版放置、其他起形路径不能抢占
        Alt松开:
            -> 按草稿与选择集回到 pointing / focused / unfocused
            待定(精确优先级)

    部件操作:
        Alt 草稿完成: 只选中新选区，保留旧选区和旧部件
        普通点击 [命中部件 / 标签 / 边框]: 单选
        Ctrl点击 [命中部件]: 追加或取消选择
        Ctrl+A [有部件]: 全选
        Gizmo拖动 [有选择集]: 移动 / 旋转 / 缩放 / 重复
        Ctrl+C [有选择集]: 复制当前预览
        Ctrl+V [剪贴板有效 + 有落点]: 创建本地部件
        Delete / Backspace:
            世界来源部件: 标记待删除
            剪贴板来源部件: 移除本地部件
        Ctrl+Delete: 移除选中部件，不删除世界方块
        Ctrl+Z:
            有本地历史: 优先撤回本会话操作
            无本地历史: 请求世界撤回
        Enter [有部件]:
            提交本会话的全部部件，不只是选择集
            服务端校验后才写世界

    变换:
        MOVE: 沿轴移动
        STACK: 按整数区间重复
        ROTATE: 围绕部件中心或公共中心旋转
        SCALE:
            棱柱: 改变尺寸
            其他部件: repeat 语义
        编辑能力:
            FREE: 允许点编辑、推拉、扩展
            LOCKED:
                禁止: 点编辑、面编辑、面高亮、扩展
                允许: 选择、整体移动、旋转、重复、复制、删除、多选、撤回
                待定(锁定后缩放能力)

    提交:
        成功: 清除全部选区和部件，包括未变换且未写入的旧选区
        本地编辑不立即改变世界
        区分: 本地草稿 / 已发送请求 / 正在恢复的世界任务
        未收到服务端恢复结果: 不显示已撤回
        成功: 待定(清理对象与去向)
        未写入失败: 待定(保留对象与重试)
        部分写入后恢复: 待定(等待与恢复后的编辑状态)

    Q / Esc:
        请求取消
        本地取消 != 服务端恢复完成
        待定(D6: 各阶段清理哪些草稿、候选和部件，何时回到空闲)
    离开设点:
        停止候选预览
        保留共享剪贴板、非本次取消的部件
    退出:
        会话切换不隐式清空部件
        待定(D6: Q 对草稿、选中部件、全部部件的分别影响)
    待定:
        PRISM 最少点数、闭合条件、高度阶段
        空草稿左键、无命中点击
        复制、粘贴、提交失败的提示与重试条件
        空闲但有部件时 Gizmo 是否显示
```
