```text
选区操作会话 selection:
    所属: 相对独立的操作会话，与其他活动会话互斥
    入口:
        Ctrl+V [输入归属 FastFormer]:
            校验剪贴板与落点
            校验成功:
                从剪贴板建立操作内容
                -> 本会话
                待定(粘贴后的初始阶段与选择集)
            校验失败:
                保持原会话，不丢失原有数据
                返回失败原因
        双击右键 / Alt+右键 [创造模式、功能开启、未手持可放置物品]:
            双击入口使用交互形状快照，Alt 入口绕过扳手
            -> 本会话.设点
            长方体双击入口: 第一击只保存交互快照，第二击进入会话并设点1
            长方体 Alt+右键或远距离单击入口: 只设置点1
            智能模式选中命中处的关联方块
            拦截入口这次右键及对应释放，不重复派发原版事件
        已在本会话内:
            Ctrl+V: 执行粘贴，不重复进入会话
            Alt新建: 切换本会话内阶段，不新增会话
    数据:
        草稿 != 已确认选区 != 操作部件
        point1、point2: 最近设置的输入点
        minPoint、maxPoint: 当前 AABB 唯一边界
        部件: 内容、来源、变换
        选择集: 当前操作哪些部件
        新建草稿不是部件本身
        访问玩家共享剪贴板
    内容来源:
        Ctrl+V 从剪贴板建立操作内容
        接收完整候选部件
        世界选区: 由改变方块集合的变换交入，见 D3
        待统一(D2: 其他完整候选的交入动作)
    显示:
        选区预览、选择反馈、可用 Gizmo
        不显示已经交入部件的原始选区副本
    约束:
        编辑草稿不隐式修改已确认部件
        普通选区输入: 创造模式 + 功能开启 + 活动选区会话，与距离无关
        expandTo: 只扩大边界，不改输入点
        普通中键 [已有选区且输入归属本会话，2026-09-19 用户确认]:
            接管本次按下与释放，不执行原版选取方块
            有合法落点且允许编辑: 扩大选区范围
            无变化、无落点或校验失败: 不修改选区，仍拦截原版
        重新设点: 重算边界，清除旧扩展
        预览读边界，不反写输入点
        无固定部件数量限制
        不使用 Ctrl + 数字槽位

    设点 pointing:
        显示: 草稿点、候选边界
        模式:
            CUBOID:
                右键: 顺序设置点1、点2；完成后下一次设点开始新长方体
                    选点后从该次物理按下计时，200ms内再次右键被忽略
                    被忽略按下的对应释放也被拦截，即使释放超过窗口
                    被忽略的点击不延长窗口；入口点、后续选点共用保护
                    不影响左键撤点、中键扩展、智能选区和操作手柄
                左键: 撤回上次选点，不需要准星命中方块
                    有草稿点: 删除最后一点
                    草稿为空、栈末为可调整长方体: 撤回点2，恢复只有点1的草稿
                    没有可撤回点: 保持状态
                    命中 Gizmo 或可调整面时保留变换操作
                中键: 填充空缺点；两点已完成时扩展最晚选区
                智能选区: 保留左键减选，不使用长方体撤点规则
            PRISM:
                右键 [未靠近首点]: 添加底面点
                右键 [靠近首点]: 闭合底面
                左键 [有草稿点]: 删除最后一点
                中键:
                    添加点或高度
                    待定(阶段条件)
        完成:
            D3 [2026-09-19 用户确认]:
                设点、修改范围等操作选区本身的行为: 仍是选区
                不因 ready、选中或按 Enter 就成为部件
                只有拖动、stack、旋转等改变方块集合的变换才使其成为部件
                拖动、stack、旋转等变换:
                    固定变换前的原始选区与方块集合
                    结果方块集合不同于原始集合: 成为部件
                    结果方块集合相同: 保持选区
                部件经过后续变换:
                    结果方块集合与原始集合相同: 变回原始选区
                    否则: 保持部件
                比较依据:
                    完整方块集合，不使用肉眼、边框或变换参数判断
                    比较世界位置、方块状态与方块实体数据
                    可先比较 hash，hash 相同时仍核对完整集合
                    使用固定的原始集合，不重新读取正在变化的世界
                交入部件后: 不再显示原始选区副本
                变回选区后: 恢复选区编辑能力与原始选区显示

    已选中 focused:
        条件: 选择集非空
        显示: 部件选择反馈、可用变换
        输入: 按本会话的部件操作规则处理
        Ctrl+R: 绕 Y 轴旋转 90°，从上方看顺时针
        Ctrl+F: 沿最接近视线的 X / Y / Z 轴镜像翻转
        单选中心: 当前选区整体边界的中心
        多选中心: 已选中选区整体边界的共同中心
        只变换已选中的完整选区，不补全草稿，不隐式提交
        每次按下产生一个撤销步骤，长按不重复变换
        保留原始快照，预览与世界提交使用相同变换
        Ctrl+F 接管该次 F，不执行原版副手交换
        旋转圆环跟随选区自身轴向，包含已有旋转和镜像
        多选圆环以最早建立的已选中选区为轴向参考，中心仍取整体中心
        旋转拖动: 自由预览，松开时吸附 atan2(y, x) 的整数比例角度
        比例范围: x、y 的绝对值为 0~64，不同时为 0，覆盖全部象限
        Ctrl+旋转拖动: 按 90° 吸附
        单选重复沿当前选区的局部手柄轴扩展，首次使用原始未旋转选区的宽度作为步长
        Scale 松开后保留原始选区尺寸、缩放参数与重复步长，不把结果设为新的原始尺寸
        再次拖动逐级增减一个原始单元，多选使用不包含已扩展副本的基础组合尺寸
        单选已有重复步长时保留该步长，不重新排列已有副本
        扩展副本保留原有方块位置，新增副本不改变旋转中心
        扩展后再旋转仍以当前整体中心为轴心

    未选中 unfocused:
        条件: 有部件，选择集为空
        显示: 可选择的部件、标签、边框
        点击部件 / 标签 / 边框:
            选中
            -> focused

    Alt新建 alt_focused:
        例外 [2026-09-19 用户确认]:
            Alt + 左键 / 右键 [直接命中 Gizmo]:
                变换命中的旧部件或公共选择集，不新建草稿
                按下时固定目标、按钮、修饰键与手势身份
                松开 Alt 不改变已开始拖动的归属
        进入:
            输入焦点交给新草稿
            旧选区、已选部件降低透明度，不清空
            保留原选择集，仅转移输入焦点 [2026-09-20 用户确认]
        模式:
            CUBOID:
                中键 [无第一点]: 设置第一点
                中键 [有第一点，无第二点]: 设置第二点
                中键 [两点已有]: expandTo
                左键撤回上次选点，右键顺序填充点1、点2
            PRISM:
                左键 / 右键 / 中键: 只编辑新草稿，按模式处理
        约束:
            除直接命中 Gizmo 的例外外，不编辑旧选区、已选部件
            旧选区、部件选择、原版放置、其他起形路径不能抢占
        Alt松开:
            -> 按草稿与选择集回到 pointing / focused / unfocused
            待定(精确优先级)

    部件操作:
        Alt 草稿完成: 只选中新选区，保留旧选区和旧部件
        普通点击 [命中部件 / 标签 / 边框]: 单选
        Ctrl点击 [命中部件]: 追加或取消选择
        Ctrl+A [有部件]: 全选；全部已选中时取消全部选择，保留所有选区
        Gizmo拖动 [有选择集]: 移动 / 旋转 / 缩放 / 重复
        Ctrl+C [有选择集]: 复制当前预览
        Ctrl+V [剪贴板有效 + 有落点]: 创建本地部件
        Ctrl+D: 复用 Ctrl+C、Ctrl+V 顺序复制粘贴；复制失败则停止
        Delete / Backspace:
            只处理已选中的部件与当前活动草稿，未选中的部件保留
            草稿只有点1或点2时: 在按键瞬间用已设点和当前候选点补全预览区域
                按与渲染相同的规则采样该区域并提交删除，允许从选点状态提交
                不要求先确定第二点，不因缺少已完成部件报“操作状态已变化”
            世界来源部件: 提交删除当前可见方块，并删除已移动部件的源方块
            剪贴板来源部件: 移除本地部件
            服务端成功后移除已提交的部件 / 草稿；删除进入世界撤销历史
        Ctrl+Delete: 移除选中部件，不删除世界方块
        Ctrl+Z:
            有本地历史: 优先撤回本会话操作
            无本地历史: 请求世界撤回
        Enter [有部件]:
            提交本会话的全部部件，不只是选择集
            服务端校验后才写世界

    变换:
        形状恢复判定 [2026-09-21 用户确认]:
            只有方块集合和选区外框都与基线相同，才恢复为原始选区
            方块集合为空时仍比较外框；仅仅都是空集合不构成相同形状
            方块状态、方块实体数据和世界坐标都属于方块集合比较
        MOVE: 沿轴移动
        STACK: 按整数区间重复
        ROTATE: 围绕部件中心或公共中心旋转
        SCALE:
            棱柱: 改变尺寸
            其他部件: repeat 语义
        编辑能力:
            FREE: 允许点编辑、推拉、扩展
            LOCKED:
                禁止: 点编辑、面编辑、面高亮、扩展
                允许: 选择、整体移动、旋转、重复、复制、删除、多选、撤回
                待定(锁定后缩放能力)

    提交:
        成功: 清除全部选区和部件，包括未变换且未写入的旧选区
        本地编辑不立即改变世界
        区分: 本地草稿 / 已发送请求 / 正在恢复的世界任务
        未收到服务端恢复结果: 不显示已撤回
        成功: 待定(清理对象与去向)
        未写入失败: 待定(保留对象与重试)
        部分写入后恢复: 待定(等待与恢复后的编辑状态)

    面法线箭头:
        面内位置的每次变化在 2 tick (100ms) 内线性过渡，连续变化叠加平滑
        法线方向与沿法线的位移立即更新，不插值
        切换到不同朝向的面时立即更新，不跨面插值
    智能选区 HUD:
        仅分离的智能选区显示整体四角框，框的位置不平滑
        屏幕外的部件继续参与整体框投影，允许框延伸到屏幕外
        内部编号固定在各部件顶部中心，组标题固定在整体顶部中心
        镜头变化实时投影，不对屏幕坐标做时间插值；标记跟随当前可见选区几何
        文字和四角框按真实屏幕像素定位，使用0.75像素滞回减少取整抖动
        世界锚点进入近裁剪面后隐藏；定位提示继续留在屏幕内
    Q: 取消待选点或栈末选区，栈空后回到空会话
    Esc: 保留原版菜单行为
    离开设点:
        停止候选预览
        保留共享剪贴板、非本次取消的部件
    退出:
        会话切换不隐式清空部件
        仅空会话中的 Q 临时交还原版，见 00-状态机.md
    待定:
        PRISM 最少点数、闭合条件、高度阶段
        空草稿左键、无命中点击
        复制、粘贴、提交失败的提示与重试条件
        空闲但有部件时 Gizmo 是否显示
```
