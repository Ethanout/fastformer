# Special Item 会话

## 目标

处理特殊物品声明的交互动作。

## 持有状态

- 当前特殊物品模式。
- 该物品自己的参数和候选反馈。

## 进入

当玩家手持特殊物品并触发该物品的启动条件时进入。

进入反馈：显示该物品声明的提示和候选反馈。

## Signal

```text
pointer.primary / pointer.secondary / pointer.middle:
  条件：特殊物品声明该 signal 可用
  动作：执行该物品的语义动作
  反馈：显示动作结果

pointer.scroll:
  条件：特殊物品声明可调节
  动作：调整该物品参数
  反馈：显示新的数值

keyboard.cancel:
  条件：始终允许
  动作：取消特殊物品动作
  转移：empty
```

## 退出

完成或取消后转移到 `empty`。不修改快速起形和工作区的内部状态。

## 不变量

- 只接收该物品声明的 signal。
- 不直接修改其他会话节点的内部字段。
- 近距离未消费输入交给原版。
