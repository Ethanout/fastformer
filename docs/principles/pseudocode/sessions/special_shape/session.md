# Special Shape 会话

## 目标

按点、线、面、体阶段创建特殊形状。

## 持有状态

- 当前工作流阶段。
- 控制点和候选参数。
- 当前形状预览。
- 当前阶段允许的动作。

## 进入

当玩家启动几何会话，或收到特殊形状的活动权威快照时进入。

进入反馈：显示当前阶段的控制点、引导线和候选形状。

## Signal

```text
pointer.secondary:
  条件：当前阶段声明右键可推进或确认
  动作：推进阶段或确认当前阶段
  反馈：更新阶段提示和预览

pointer.primary:
  条件：当前工作流声明左键可回退
  动作：回退当前阶段或删除最后一个控制点
  反馈：更新控制点和预览

pointer.scroll:
  条件：当前阶段声明可调节
  动作：调整当前参数
  反馈：显示新的数值

keyboard.enter:
  条件：形状状态已确认
  动作：提交已解析的形状
  反馈：进入提交或失败处理

keyboard.cancel:
  条件：始终允许
  动作：取消当前形状会话
  转移：empty
```

## 退出

停止当前工作流预览。已提交的世界任务不因玩家离开本会话而停止。

## 不变量

- 近距离输入交给原版。
- 远距离命中 Gizmo 时进入拖动。
- 滚轮只能调整当前阶段声明的参数。
- 预览降级为轮廓时不能生成可提交形状包。
