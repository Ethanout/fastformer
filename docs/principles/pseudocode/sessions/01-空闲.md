# 空闲
[返回会话树](README.md)

```text
空闲 empty:
    含义: 没有活动的起形、特殊形状、特殊物品或选区操作会话
    数据:
        无自有活动草稿
        访问保留的选区数据、玩家共享剪贴板

    进入:
        其他会话明确完成或取消 -> 空闲
        暂时没有快照: 不据此取消原会话

    显示:
        隐藏所有组件
        显示一个白色方块，语义为下一次操作的目标位置。
            -> 如果手持可放置物品，则在raycast处（原版可被右键直接覆盖的方块视为空气，如草）显示蓝色的方块虚影，并根据是否长按Alt决定raycast是否嵌入方块
            -> 如果手持空气，则在准星指向的方块显示虚影
            tips: raycast规则和原版交互逻辑一致。放方块时方块会根据玩家朝向和放置面决定方块状态，raycast在方块表面；空手时raycast会嵌入方块。虚影为白色。

    输入:
        右键 [手持方块 + 远距离 + 输入归属 FastFormer]:
            传入入口来源、右键点
            -> 快速起形.线
        启动动作 [手持特殊物品]:
            -> 特殊物品
        点击 [空手 + 近距离命中方块]:
            -> 扳手行为
            待定(扳手具体动作，是否仍在空闲)
        鼠标 [近距离 + 非扳手 + 归属原版]:
            原版
        活动权威快照 [属于当前玩家]:
            -> 对应会话
        Ctrl+V [输入归属 FastFormer]:
            请求进入选区操作会话(入口=粘贴)
            入口校验与初始化见 10-选区.md
        左键 / 中键 / 右键 [满足选区输入条件]:
            请求进入选区操作会话(入口=鼠标，携带本次按键与命中)
            入口校验与初始化见 10-选区.md
        进入失败:
            保持空闲，不丢失原有数据

    退出:
        保留选区数据、玩家共享剪贴板

    待定:
        从空闲进入特殊形状的入口
```
