# 空闲

[返回会话树](README.md)

```text
空闲 IDLE:
    含义: 没有活动起形、几何或选区会话
    进入: 完成或取消活动会话后返回同一空状态
    未命中会话入口的普通左键、中键、右键、滚轮、Q: 原版行为，不建立草稿
    保留现有强制放置、世界撤回和剪贴板功能
    模组放置南瓜或西瓜种子时，普通梗默认满阶段；物品显式指定的方块属性和已保存快照优先
    近距离强制放置门: 上下两格通过同一事务写入，一次世界撤回同时恢复两格
        上半格被占用、越界或不允许修改时，整次放置取消，不留下单独的下半门

    显示:
        底部入口提示: 对准方块，按住 Alt+右键或双击右键；短按 Alt 切换模式
        超出玩家方块交互范围时，入口提示改为直接右键；手持方块另提示中键嵌入并提交
        底部模式: 手持可放置物品显示起形线模式，否则显示长方体/智能选区模式
        读取当前会话归属，取消最后一个选区后立即显示空会话提示
        活动选区内换手持物品不改变会话归属
        不显示点/线阶段操作提示或顶部填充提示
        命中距离超过玩家当前 block_interaction_range 时:
            手持可放置物品: 显示放置虚影，保留方块模型和呼吸透明度
            其他情况: 显示命中方块的选区预览框
            预览和入口共用射线规则，不建立草稿，不改变输入归属
        原版交互范围内不显示空会话虚影或选区框

    命中距离超过玩家当前 block_interaction_range:
        无需 Alt 或双击，右键直接使用表面入口进入起形/选区
        手持可放置物品时，中键直接使用嵌入入口并提前提交首点
        扳手不生效，直接使用会话入口
        单击右键成功进入后，从该次物理按下开始计时，200ms内再次右键按下被忽略
        被忽略的按下与松开配对，不产生会话操作；重复点击不延长保护窗口
        左键、中键与近距离双击入口保持原有行为
        取消会话、打开界面、失去焦点或切换世界时清理保护
        空手左键: 直接删除命中方块，不产生破坏粒子，不建立会话
            删除复用方块编辑事务、世界撤回与扳手历史后台合并器
            距离档位、合并上限、最近5条保护、分组配置和禁止合并标签沿用扳手规则
            Alt按下状态随射线请求保存，流体穿透规则与选区预览一致
        预览与入口使用同一距离判定，读取玩家现有属性
        不改变活动会话的操作，不恢复距离交接状态

    短按 Alt [未被其他操作消耗，时长不超过250ms]:
        手持可放置物品: 切换起形线模式
        其他情况: 切换长方体/智能选区模式
        保持空状态，模式延续到下次进入

    Alt+右键:
        绕过扳手，立即进入会话并设置第一点
        手持可放置物品 -> 起形.线
        其他情况 -> 选区，长方体设置点1，智能模式加选关联方块
        消耗本次 Alt，不在松开时再次切换模式
        起形首点使用普通放置位置，不嵌入命中方块

    Alt+中键 [手持可放置物品]:
        绕过扳手，以命中方块内部为第一点
        在嵌入位置重新计算方块状态
        按中键的提前提交语义提交该点，完成后回到空会话
        消耗本次 Alt，松开中键不拾取方块、不重复提交
        表面/嵌入的按键区分仅适用于空会话入口，活动会话沿用原有操作

    普通右键:
        空手、扳手开启、命中位于玩家方块交互范围内且存在可用动作:
            第一击立即执行扳手，仍为空会话
            保存受影响方块的原始状态和第一次点击后的状态，包含连体方块和方块实体数据
            第二击在200ms内、视线方向变化不超过2°、快照命中点间距不超过1/2格:
                服务端校验并恢复原始状态，再进入选区
                全部还原位置先同步给客户端，再确认入口；选区使用还原后的状态计算形状
                长方体在第二击进入会话并设置点1，第一击不是选点
                智能选区沿用首次关联加选
                不再执行第二次扳手操作；取消第一击对应的世界撤回步骤
            无有效第二击: 保留第一击结果及世界撤回步骤
        否则:
            第一次物理按下:
                保存时间、环境、主手物品、交互位置与实际方块外形
                保留本次原版交互
                若产生放置，使用实际放置方块的外形取代命中外形
                保存首次放置上下文；放置成功时保存实际方块的完整状态
                未产生放置时，保留首次上下文计算出的手持方块状态
            再次物理按下 [相隔不超过200ms，视线方向变化不超过2°]:
                比较两次视线方向的夹角，玩家位移不算视角变化
                对保存外形额外发射射线，不重新读取该位置的世界形状
                第一条射线也投射到同一快照外形，两次落点间距不超过1/2格才算双击
                射线穿过快照 -> 进入起形/选区
                    起形设置首点，智能选区加选关联方块
                    近距离双击起形的预览和提交共用首次状态快照，不按第二击朝向、命中面或周围方块重新计算
                    会话中换用其他物品时，使用冻结上下文重新计算新物品状态
                    长方体在第二击进入会话并设点1；Alt+右键或远距离单击入口也只设点1
                射线未穿过或已超时 -> 作为新的第一次点击
            长按重复不是第二次物理按下，不启动会话
            第二击启动会话后不执行第二次原版放置

    快照生命周期:
        只接受相同令牌、环境和主手物品的网络结果
        Q、进入会话、换物品、换世界、打开界面或失去焦点时失效
        迟到结果不创建快照、不启动会话
        服务端校验权限、忙碌状态、射线和保存的实际形状

    扳手距离:
        使用玩家当前 block_interaction_range，客户端和服务端共用距离规则
        不提供 /ff tinker reach 命令

    原版方块交互范围:
        基础值默认20格，首次初始化后不覆盖玩家后续修改
        /ff reach <整数>: 直接设置 minecraft:player.block_interaction_range 的基础值
        /ff reach: 显示当前有效范围及基础值
        读取与限制遵循原版属性，保留属性修饰器，不修改实体交互范围
        重连、换维度、重生时保留当前基础值

    Ctrl+V: 按原有剪贴板规则进入选区
    活动权威快照: 恢复对应会话，不用临时空快照取消原草稿
```
