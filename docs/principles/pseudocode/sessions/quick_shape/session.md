# Quick Shape 会话

## 目标

让玩家通过点位快速生成待编辑部件。

## 持有状态

- 当前形状模式。
- 选区草稿。
- 当前候选预览。
- Alt 新建状态。

## 进入

当玩家开始快速起形，或收到快速起形的活动权威快照时进入。

进入反馈：显示当前形状候选和可用的点位反馈。

## Signal

```text
pointer.primary:
  条件：创造模式、功能开启、目标在远距离、当前模式允许左键
  动作：按选区模式设置或编辑点位
  反馈：刷新候选预览

pointer.secondary:
  条件：创造模式、功能开启、目标在远距离、当前模式允许右键
  动作：按选区模式设置、添加或闭合点位
  反馈：刷新候选预览

pointer.middle:
  条件：当前选区模式允许中键
  动作：设置第二点，或在 Alt CUBOID 中扩展边界
  反馈：刷新候选预览

keyboard.enter:
  条件：选区已完成
  动作：把草稿转换为工作区部件
  转移：operation_workspace

keyboard.cancel:
  条件：始终允许
  动作：取消当前草稿和候选预览
  转移：empty

session.snapshot:
  条件：快照属于当前玩家且为活动权威快照
  动作：更新会话和预览状态
  转移：保持 quick_shape
```

## 选区规则

### CUBOID

- 左键设置第一点。
- 右键或中键设置第二点。
- Alt 中键在两个点存在后调用 `expandTo`。

### PRISM

- 右键添加点，靠近首点时右键闭合。
- 左键删除最后一个草稿点。
- 中键按当前输入路径添加点或高度。

## 退出

停止候选预览，但保留玩家盒子中的持久剪贴板和未提交工作区对象。

## 不变量

- 只有远距离创造模式输入由本会话消费。
- `point1` 和 `point2` 只记录最近设置的点。
- `expandTo` 不能修改 `point1` 或 `point2`。
- Alt 路径不被旧选区、部件选择、原版放置或其他快速起形路径抢占。
