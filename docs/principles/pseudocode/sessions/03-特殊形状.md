# 特殊形状
[返回会话树](README.md)

```text
特殊形状 special_shape:
    进入:
        启动几何会话
        或收到属于当前玩家的活动权威快照
    数据:
        形状模式、阶段、控制点、候选参数
        已确认形状、完整预览
    显示:
        控制点、引导线、候选形状、阶段提示

    形状 待填:
        阶段 待填:
            已确认: 待填
            候选: 待填
            显示: 待填
            输入:
                右键 [允许推进]:
                    确认当前阶段
                    -> 待填(下一阶段)
                左键 [允许回退]:
                    回退或删除最后控制点
                    -> 待填(精确目标)
                滚轮 [声明可调参数]:
                    修改该参数，显示数值
                Enter [已确认形状满足提交条件]:
                    使用已确认的形状
                    -> 待定(D2: 写世界还是交入选区会话)
                拖动 [远距离命中 Gizmo]:
                    更新变换
                    待填(按钮、释放结果)
                鼠标 [近距离 + 归属原版]: 原版
                Q [尚未发送]:
                    取消当前草稿和预览
                    -> 空闲
                Esc: 保留原版菜单行为
                中键: 待定
                模式切换: 待定
                空候选或超限: 待定

    退出:
        明确退出才清理当前草稿和预览
        保留上次形状模式
        已发送任务不因退出而停止
        服务端取消与恢复另行处理

    撤回与命中删除的边界:
        撤回一步不使用光标命中坐标，也不使用世界原点作为占位目标
        阶段规则要求删除最后控制点时，按点的顺序删除
        明确删除命中控制点时，才按目标点匹配；世界原点是合法控制点
        各形状阶段的具体回退目标仍按 D5 待核对

    待统一:
        D4.预览:
            旧页: 可以轮廓降级，降级预览不能提交
            此前批准计划: 默认完整计算，等待时保留旧完整虚影
        D5: 各形状各阶段回退目标
        计算中 Enter、Q、失败重试的行为
```

几何鼠标默认规则位于 `bindings/default/geometry.json`，滚轮位于 `scroll.json`，确认与取消分别位于 `confirmation.json`、`cancellation.json`。形状可用目标仍由各形状的纯交互计划声明；绑定规则选择原子动作，输入边界捕获并排队。

| 输入阶段 | 按优先级执行的默认行为 |
| --- | --- |
| 松开 | 已捕获手柄排队结束；已捕获指针释放；旧放置撤回仅在 250ms 内完成。物理清理始终执行。 |
| 已按住手柄 | 相同物理按钮继续吞入；其他按钮放行。 |
| 普通按下 | 手柄优先；其次复用已捕获指针；原版占用时放行。 |
| 左键目标 | 执行计划中左击动作；无目标且无选点时撤回控制点；已有选点时清选；其他情况只捕获。 |
| 右键目标 | 执行计划中右击动作；无目标但有选点时清选；其他情况只捕获。 |
| 路径备用入口 | 无 interaction／undo 通道且存在合法路径候选时，右击按冻结的悬停／双击事实请求加点或闭合。 |
| 滚轮 | 所属路由允许候选调整时，Alt 放行原版；其他情况下调整候选。任务忙碌时阻断。 |

默认资源保留原入口优先级。用户可以按 session／mode／事实覆盖规则；禁用整个几何子树后，不再回落到旧物理按钮路径。资源重载取消旧捕获并使尚未执行的几何事件失效。默认规则的组合对照与队列回归已写，整批执行结果以阶段报告为准。
