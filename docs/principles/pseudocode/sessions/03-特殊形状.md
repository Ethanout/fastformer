# 特殊形状
[返回会话树](README.md)

```text
特殊形状 special_shape:
    进入:
        启动几何会话
        或收到属于当前玩家的活动权威快照
    数据:
        形状模式、阶段、控制点、候选参数
        已确认形状、完整预览
    显示:
        控制点、引导线、候选形状、阶段提示

    形状 待填:
        阶段 待填:
            已确认: 待填
            候选: 待填
            显示: 待填
            输入:
                右键 [允许推进]:
                    确认当前阶段
                    -> 待填(下一阶段)
                左键 [允许回退]:
                    回退或删除最后控制点
                    -> 待填(精确目标)
                滚轮 [声明可调参数]:
                    修改该参数，显示数值
                Enter [已确认形状满足提交条件]:
                    使用已确认的形状
                    -> 待定(D2: 写世界还是交入选区会话)
                拖动 [远距离命中 Gizmo]:
                    更新变换
                    待填(按钮、释放结果)
                鼠标 [近距离 + 归属原版]: 原版
                Q / Esc [尚未发送]:
                    取消当前草稿和预览
                    -> 空闲
                中键: 待定
                模式切换: 待定
                空候选或超限: 待定

    退出:
        明确退出才清理当前草稿和预览
        保留上次形状模式
        已发送任务不因退出而停止
        服务端取消与恢复另行处理

    待统一:
        D4.预览:
            旧页: 可以轮廓降级，降级预览不能提交
            此前批准计划: 默认完整计算，等待时保留旧完整虚影
        D5: 各形状各阶段回退目标
        计算中 Enter、Q、失败重试的行为
```
