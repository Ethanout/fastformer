# 伪代码树模板
[返回会话树](README.md)

直接改节点名称和缩进内容。新增模式或阶段就在对应位置加分支。

```text
名称 标识:
    所属: 待填(互斥会话 / 会话内阶段 / 共享层)
    用途: 待填
    不负责: 待填
    数据:
        已确认: 待填
        候选: 待填

    enter(来源, 数据):
        初始化: 待填
        不判断是否进入，不请求下一次切换

    阶段 待填:
        已确认: 待填
        候选: 待填
        显示: 待填

        模式 待填:
            进入模式: 待填
            鼠标移动: 待填
            onEvent(事件):
                左键按下 [条件]:
                    待填(动作)
                    返回 切换(目标=待填, 数据=待填, 原因=待填)
                右键按下: 待填
                中键按下: 待填
                拖动: 待填
                释放: 待填
                滚轮: 待填
                Alt按下: 待填
                Alt松开: 待填
                Enter:
                    使用数据: 待填(已确认 / 当前候选)
                    计算中: 待填
                    连续按下: 待填
                    等待时修改: 待填
                    -> 待填
                Q / Esc:
                    尚未发送: 待填
                    已经发送: 待填
                    -> 待填
            拒绝:
                条件: 待填
                提示: 待填
                不得修改: 待填

        tick(输入快照):
            持续更新: 待填
            如果满足持续退出条件:
                返回 切换(目标=待填, 数据=待填, 原因=待填)
            返回 保持

    exit(原因):
        清理阶段临时资源: 待填
        不请求切换，不自动删除整个草稿

    切换请求中的本地业务动作:
        正常完成:
            删除: 待填
            保留: 待填
            -> 待填
        左键回到入口: 待填
        Q / Esc: 待填
        切换功能或物品: 待填
        重生 / 换维度 / 断线: 待填
        提交失败:
            保留: 待填
            重试: 待填

    验收:
        场景名称:
            初始: 待填
            操作: 待填
            状态: 待填
            画面: 待填
            世界变化: 待填

    待定:
        待填(尚未决定的问题)
```

不支持的输入明确写“无操作”或“原版”。未决定写“待定”，不要让实现猜测。共同规则不是父节点自动处理器，活动节点必须明确注册事件。
