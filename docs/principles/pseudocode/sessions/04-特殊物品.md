# 特殊物品（待定）
[返回会话树](README.md)

```text
特殊物品 special_item:
    进入:
        手持特殊物品，满足物品声明的启动条件
        待定(仅手持是否足以启动)
    数据:
        物品模式、参数、动作草稿、候选反馈
    显示:
        物品自己的提示与候选

    物品 待填:
        启动条件: 待填
        模式 待填:
            阶段 待填:
                输入:
                    左键 / 右键 / 中键 [物品注册该事件]:
                        执行物品声明的动作
                        显示结果
                        -> 待填
                    滚轮 [声明参数可调]:
                        调整参数，显示数值
                    Q / Esc [本地动作未结束]:
                        取消草稿
                        -> 空闲
                    鼠标 [近距离 + 归属原版]: 原版
                完成:
                    -> 空闲

    约束:
        只处理物品声明的事件
        未注册事件不冒泡，也不自动让给原版
        不直接修改起形或选区会话内部状态
    退出:
        明确退出才清动作草稿
        保留上次模式
    待定:
        逐种填写物品和启动条件
        切换手持物品: 保留 / 暂停 / 取消
        世界写入的确认、失败、取消流程
```
