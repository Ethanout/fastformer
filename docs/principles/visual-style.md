## 主题

客户端配置使用 `visual.theme`，在 `FastFormerSettingsScreen` 中切换。

- **经典 CLASSIC（默认）**：九月初的配色。白色主线，蓝色起点、黄色控制点、绿色悬停，颜色区别清楚。
- **人文 HUMANIST**：暖白色铅笔主线，淡深色光晕。赭黄表示悬停或可拖动，砖红表示冲突，鼠尾草绿表示有效。
- 白色的依据：“在大部分场景中白色会更清楚”。

## 线条

- “不用虚线区分候选和已确认”。候选用低透明度实线，已确认用全透明度实线。人文主题另用虚线表示被方块模型遮挡的部分，未遮挡部分保持实线。
- 经典主题默认隐藏被遮挡的线段。两套主题共用遮挡接口，资源包可调整遮挡透明度和虚线样式。
- 人文遮挡虚线恢复为未遮挡线透明度的 30%，取代短暂采用的等透明度规则。
- 保持线条数量少，以外轮廓为主，不逐块绘制密集接缝。逐块虚线“很花，效果不太好”。
- 两套主题的线条都要清晰可辨，不能过细。人文主题需要能辨认的铅笔／粉笔／蜡笔质感，仅换色不满足要求。
- 线宽使用逻辑 GUI 像素，主线、操作轴、描边和笔触横向颗粒共同跟随 Minecraft 界面缩放。
- 人文主题保留略微越过交点的笔触（overshoot），删除角落附近额外的短辅助线。用户明确：“i dont need these end short bars (not the overshoots) in the corner”。
- 人文线条每边一长一短，按轴向交替安排两端；交点的视觉平衡允许少量例外。长端 0.15～0.35 格，短端 0.02～0.15 格，坐标哈希只控制范围内的变化。短线同比缩短，静态延伸不随时间或相机移动变化。
- 人文线条靠近时适度加粗并保留实心笔画主体，远处保留粗颗粒。动态偏移按逻辑 GUI 像素计算，取代随距离放大的世界单位抖动。
- 动态部分轮换有限画稿，默认 3 张、每秒 8 次，不连续重复。角点共享偏移，线条最多只有一个微弯。静态部分使用画稿 0，零偏移。
- “框太板正了，看起来不像是在纸上画的”。人文主题采用清楚的彩铅草图和翻页动画式轻微抖动。
- “这是针对动态部分来说的。该是静态的部分就静止”。只有候选、待确定、移动或拖动部分抖动，已确认的静态标记保持静止。
- 参考图：`.temp/style-reference/humanist-pencil-reference.png`。“就是这种样子，像在平面上画出来的一样”。
- 线宽以全屏截图 `.temp/style-reference/humanist-line-width-reference.png` 为基准。用户确认原版风格合适，只需微调粗细与动画强度，保留白色笔触、颗粒和长短延伸。

## 放置预览

- 通过一个共用接口绘制方块模型，并对预览区域应用后处理着色器。
- 已确认部分：目标方块模型，85% 不透明度。
- 待确定部分：目标方块材质，在 5%～30% 不透明度之间呼吸。可微调数值，但必须容易区分两个阶段。
- 没有可用材质或模型时，回退到默认幽灵方块。
- 人文主题应用铅笔草图着色器。排线以世界坐标和面法线为依据，固定在所属面上，不能随相机滑动。
- 经典主题可以给已确认部分加少量白色。
