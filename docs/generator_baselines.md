# 生成器回归基线

本文只记录生成长期不变量和验证入口。

- 平面、棱柱、棱锥、墙体、锥柱台体、球体、任意凸多面体和复合形状使用独立生成器。
- 只共享确实同义的离散线、数值、数学和限额工具。
- 离散直线按当前线段的绝对位移动态排序 A / B / C 轴，只允许 A、AB、ABC 步；同一 owned edge 的内部点在 XOY、XOZ、YOZ 三个投影中不得形成 L，真实几何角点允许 L / T。
- 开放平面按最接近法线的主轴建立一个解析离散平面，每个主投影列只恢复一次逻辑高度；四条 owned edge 再以 `LineGenerator` 原始三维点集作为不可删约束并入，不能用二维边界替代真实边。
- 投影中的对角接触只向面内补一个正交列。物理高度接缝从同一份不可变列快照同时生成“统一向低侧支撑”和“统一向高侧支撑”两个候选，按上下包络盆地、严格低点、非边界厚度和新增方块数稳定选优；禁止逐个 `2×2` 局部换侧或递归加厚。
- 非 owned-edge 主投影列最多两层，owned edge 自身可能因真实三维线在同一主投影列占据多个高度而更厚。补合物理接缝不能新增主投影域之外的列，也不能删除任一真实边点。
- 封闭凸体先生成连续 half-space 的中心采样目标，再并入真正 owned 的面和边；中间层的边框平移副本不是几何边，不得作为不可删壳层叠加。两者合并后沿选定列轴补齐整数区间，连续目标不得被形式边界裁掉。
- 最终 `SOLID` 必须同时包含连续目标和 owned 几何约束，且无五邻居单面开口或封闭空气；倾斜或旋转形状不能因两套离散相位叠加留下与外界连通的内部空气。
- `HOLLOW` 是同一最终 `SOLID` 的六邻域外露边界与 owned outline 的并集。极少数 owned voxel 可以严格位于连续体内部；必须保留该点，但不得为了把它挖成物理边界而删除连续内部体素。
- 倾斜平行六面体只把已确认的底面、顶面和四条顶点挤出线作为形式壳层；不得机械平移中间底面或边框。垂直挤出仍须保持每个截面等于同一个已确认底面。
- `OUTLINE` 表达真实边或形状约定的代表性轮廓，不能用空心外壳冒充。
- `maxBlocks` 是输出硬上限；超限必须在详细枚举前拒绝或降级。
- 详细预览达到上限时不得把 worker prefix 当作完整形状；保留渐进网格，同时至少合并完整 `OUTLINE` 表达体的真实范围。世界写入仍以 `maxPlacement + 1` 哨兵拒绝超限结果，不能放置 prefix。

发现漏面、多一圈、孔洞或表面不一致时，先在 `tools/voxel_lab` 加最小失败样例，再加入对应 Java 回归。
