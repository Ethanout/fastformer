# FastFormer

> 一个面向 Minecraft 1.21.1 创造模式的 NeoForge 建筑辅助模组。  
> 目前处于早期测试阶段，操作和存档格式都还可能变化，**请勿在未备份的正式存档中使用**。

---

## 设计目标

在不改变原版操作习惯的前提下，把**远距离起形**、**几何生成**和**选区变换**整合到一套连贯的交互流程里。

当前已实现的功能：

- 从点→线→面逐步生成体积的快速起形工具
- 墙体、球体、多面体、锥/柱/台体等几何生成
- 长方体与棱柱选区
- 选区移动、旋转、重复、复制、删除
- 多选区及客户端剪贴板
- 世界修改历史与撤回

模组尽量将近距离点击操作交还给原版逻辑，不依赖 Mixin。预览和选区工作主要在客户端完成，最终修改世界时由服务端执行。

---

## 构建

- JDK 21
- Minecraft 1.21.1 + NeoForge 21.1.233

```bash
./gradlew.bat test --console=plain
./gradlew.bat build --console=plain
```

构建产物位于 `build/libs/`。
